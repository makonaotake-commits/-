## 0. サマリー（結論）

1. **市場はあるが、言い方に注意が必要**。猫の飼育頭数は約885万頭で、犬より多い状態が続いている【二次】。猫の CKD は年齢とともに増える代表的な病気とされる【一次・論文】。ただし、国内の「CKD の猫が何頭いるか」の公的な推計は見つからなかった【要確認】。
2. **競合のすき間は「日本語」「CKD のケアに特化」「獣医師に見せるレポート」「心に余裕のあるデザイン」の組み合わせ**。汎用の健康記録アプリは多い。一方で CKD 特化や補液記録に強いアプリは、英語の個人開発アプリが中心だった【推測：App Store の掲載情報をもとに判断】。
3. **法人パートナーは、フード・療法食メーカーを第一候補として進めてよい**。ただし、**療法食の商品広告を中心にはせず**、啓発コンテンツのスポンサーやブランド協賛から始めることを提案する。療法食は「獣医師の指導のもとで使う」前提の製品なので、飼い主へ直接商品を勧めると、かかりつけ医の方針とぶつかったり、信頼を損ねたりするおそれがある。
4. **広告モデルの最大のリスクは「記録したデータに合わせて広告が出る」と感じさせること**。第1弾では**記録データを広告に使わない**ことを提案する。あわせて、記録画面・レポート画面・お別れ後の画面には広告を出さない。

**使うときの注意**：
- 「◯割の猫が腎臓病」は、注意を引く一方で、恐怖をあおる表現にもなりやすい。対外的に数値を使う場合は、出典を明記したうえでロシアンのレビューに回す。
- 人の CKD の数値（eGFR など）とは混ぜない。

## 2. 3C 分析

### Customer（飼い主さん）

主役は「**診断直後から在宅ケア中の飼い主さん**」（`kickoff_answers.md` #1）。詳しいペルソナはブリショーが作る。以下はマーケの観点からの仮説【推測】。

| 段階 | 気持ち・困りごと（仮説） | アプリに期待しそうなこと |
|---|---|---|
| 診断直後 | 「腎臓病」「ステージ」と言われて頭が真っ白。ネット検索で不安が増す。「もっと早く気づけば」と自分を責める | 何を記録すればいいかが分かる。次の通院で獣医師に聞きたいことをメモできる |
| 在宅ケア中 | 補液や投薬が毎日続いて大変。食べない日の焦り。家族間で「あげた？」の確認が要る。多頭飼いだと記録が混ざる | 迷わず短時間で記録できる。リマインダー。数値や体調の流れを獣医師に見せられる |
| 終末期・お別れの後 | 決断の重さ、喪失感 | 通知や広告が届かないようにする配慮、思い出の扱い（要件はブリショーと相談） |

### Company（自社）

- **強み**：運営者（ユーザー）が獣医師で、監修を担う（`kickoff_answers.md`）。現場の勘所が分かり、コンテンツの信頼性を担保しやすい。
- **弱み**：第1弾は動物病院と連携しない。開発期間は3か月以内。初期の知名度はゼロ。
- **注意**：運営者と監修者が同一人物なので、**利益相反の見え方**（スポンサーのフードを監修者が勧めているように見えないか）に配慮が必要（§5）。

## 4. 法人パートナー候補の比較

前提：収益は「フード・療法食メーカーの広告」（`kickoff_answers.md` 追加決定）。第1弾は動物病院と連携しない。

| 観点 | ① フード・療法食メーカー（第一候補） | ② ペット保険 | ③ 動物病院・病院グループ | （参考）④ 検査会社 |
|---|---|---|---|---|
| 相手にとってのメリット | 腎ケア中・シニア猫の飼い主に、ブランドを正しく知ってもらう接点。啓発活動の実績 | 加入者の健康を支える支援、高齢の契約者が長く続けてくれること、新規の見込み客との接点 | 再診時の情報が整理されて届く、在宅ケアの質が上がる | 検査値の意味を正しく理解してもらう、啓発 |

### 結論

1. **第一候補はフード・療法食メーカーのままでよい**。ただし、**入り方を「療法食の商品広告」ではなく「啓発の協賛」にする**ことを提案する。
   - 例：「補液の準備のコツ」「通院前に整理しておくこと」など、**ケアの一般情報コンテンツの協賛**（企業名を明示する。監修は獣医師＝ユーザー、表現はロシアンが確認）
   - 例：アプリ全体の「サポート企業」としての掲載（1社独占にしない）
   - 商品広告を出すなら、まずは**総合栄養食やシニア向けの一般食など、獣医師の指導が前提ではない製品**に限るのが安全【推測：ロシアンに判断を依頼】
2. **ペット保険は第2弾以降の有力な追加候補**。シニア猫の健康支援という切り口で協賛を打診する。新規加入の勧誘（送客）は慎重に扱う。
3. **動物病院は「収益源」ではなく「信頼の源」**。第1弾は連携しないが、「獣医師に見せるレポート」が診察で役に立った実績を作ることが、後の B2B2C とメーカー協賛の両方の説得材料になる。
4. **1社独占より複数社の協賛**のほうが中立性を保ちやすい。ただし初期は1〜2社から始まる可能性が高い【推測】。

## 5. 広告モデルが飼い主さんの信頼に与えるリスクと対策

### 5-1. リスク

| # | リスク | 具体的な場面 |
|---|---|---|
| R1 | 健康データを広告に使っていると感じさせる | クレアチニンを記録した直後に腎臓病フードの広告が出る →「見張られている」と感じる。実質的に「この数値ならこのフード」と食事を提案しているように見える（「判定・提案はしない」方針〔kickoff #2〕と矛盾し、獣医師法の論点にもなりうる） |
| R2 | 中立性への疑い | 「無料なのはフードを売るためでは」「監修獣医師がスポンサーのフードを推しているのでは」（運営者と監修者が同一人物であることによる利益相反の見え方） |
| R3 | かかりつけ医の方針との衝突 | 獣医師に処方された療法食とは別の商品の広告を見て、飼い主が自己判断でフードを切り替える |
| R4 | タイミングの配慮不足 | 食べてくれない日や、お別れの後に、フードの広告が出る |
| R5 | 表示の問題 | 広告に「腎臓に良い」など効果を思わせる表現が入る。体験談で効果をほのめかす |
| R6 | 広告 SDK によるデータ送信 | 第三者の広告 SDK が端末の識別子や行動データを集め、飼い主さんが知らない形でデータが流れる |

### 5-2. 対策（提案）

| 対策 | 対応するリスク | 担当・確認先 |
|---|---|---|
| **第1弾では記録データを広告のターゲティングに使わない**。出し分けは、どの画面を見ているかによる文脈の出し分けまで、または出し分けなし | R1・R6 | 方針はユーザーが判断（§7）。仕様はブリショー、プライバシーはロシアン |
| **広告を出さない画面を決める**：記録の入力画面、検査値・グラフの画面、獣医師に見せるレポート、お別れ後の画面 | R1・R4 | ブリショー（画面一覧に反映） |
| 広告・協賛枠には必ず「広告」「協賛：◯◯社」と表示する。デザイン上も記録画面とはっきり分ける | R2・R5 | デザイン、ロシアン |
| **「広告と中立性の方針」ページを公開する**：データを広告に使わないこと、監修者と運営者の関係、協賛企業の一覧、協賛企業はコンテンツの内容に口を出せないこと | R2 | ベンガルが下書き → ロシアン → ユーザー |
| 療法食の広告を出す場合は「療法食は獣医師の指導のもとで与えるもの」と明記し、「かかりつけの獣医師に相談を」と案内する。購入への直接リンクは慎重に判断する | R3・R5 | ロシアン |
| 広告クリエイティブはすべて事前に審査する（効能表示・体験談・ビフォーアフターは使わない） | R5 | ロシアン → 監修獣医師 |
| 第三者の広告ネットワーク（SDK）は使わず、**自社で掲載する協賛枠**（直接契約）にする | R6・R1 | ブリショー（非機能要件）、ロシアン |
| 協賛契約に「編集の独立」の条項を入れる（企業は記事の内容を指示できない） | R2 | ユーザー（契約）。法務の確認を推奨 |

### 5-3. 広告表現の法的な論点（**判断はロシアンに依頼**）

ベンガルは論点を挙げるだけです。

1. フード広告の効能表示（「腎臓の健康維持」などの表現をどこまで使えるか）。景品表示法、ペットフード公正競争規約、薬機法（動物用医薬品と誤認されるおそれ）
2. 療法食を飼い主へ直接広告することの扱い（公正競争規約での療法食の定義、日本獣医師会の「適正使用」の考え方との関係）
3. 監修獣医師が運営者本人であることの開示方法と、協賛企業の製品との距離の取り方（ステマ規制〔景品表示法の告示〕を含む）
4. 記録データを広告に使う場合の同意取得と利用目的の明示（個人情報保護法。猫のデータでも、飼い主に結びつけば個人情報になりうる）
5. アプリの文言が「診断・治療方針の提示」にあたらないか（獣医師法）。特に広告とデータの組み合わせ
6. ペット保険と提携する場合、保険の募集にあたるか（保険業法）

## 7. ユーザー（獣医師・運営者）に判断してほしい点

1. **記録データを広告に使うか**：ベンガルとしては、第1弾は「使わない」を推奨。
2. **メーカーとの組み方**：「啓発コンテンツの協賛」から入るか、最初から商品広告を出すか。ベンガルとしては協賛から入ることを推奨。
3. **療法食の広告を扱うか**：扱わない、または獣医師への相談を必ず案内する形に限る、のどちらにするか。
4. **監修者と運営者が同一であることの開示**：開示の方法と、協賛企業の製品を監修者が勧めないというルールを設けるか。
5. **ペット保険**：第2弾以降の候補として検討を始めてよいか。
