【先生のお名前】先生

突然のご連絡失礼いたします。獣医師の【運営者の氏名】です。
現在、慢性腎臓病（CKD）の猫と暮らす飼い主さんのための記録アプリ「【アプリ名】」を準備しています。
アプリやストアの説明、SNS で発信する内容を、運営者以外の獣医師の目でも確認していただきたく、ご相談のご連絡をいたしました。

## 1. アプリについて

- 飼い主さんが、毎日の体調・皮下輸液・投薬を記録し、診察のときに獣医師へ見せるレポート（PDF）を作れるアプリです。
- **記録と見える化だけを行います。** 病期の判定、治療・食事・補液量の提案、基準値による色分けはしません。
- 記録は飼い主さんの端末の中だけに保存されます。運営者は飼い主さんの記録を持っていません。
- 運営と監修は【運営者の氏名】（獣医師）が行っています。運営者は動物病院を開設しておらず、勤務もしていません。
- 収益について：第1弾は広告を掲載しません。将来、ペットフードメーカーの広告・協賛を掲載する予定です。

## 2. ご確認いただきたい範囲

| 対象 | 内容 | 量の目安【推測】 |
|---|---|---|
| アプリ内の文言 | 記録画面の項目名・説明、通知の文言、免責の表示 | 【◯】画面分 |
| 獣医師に見せるレポート（PDF）の見本 | 構成と注記の文言 | 1〜2ページ |
| ストアの掲載文 | タイトル・サブタイトル・説明文 | A4 1枚程度 |
| Instagram の発信方針 | 投稿のテーマの柱と、代表的な投稿数本 | 【◯】本 |

- ご確認いただきたいのは、**一般的な獣医療の情報として内容が正確か、飼い主さんに誤解を与える表現がないか** です。
- 個別の猫の状態についてのご判断は、お願いしません。
- ご確認の結果をどう反映するかの最終判断と責任は、運営者が負います。

**時期（仮）**：【2026年12月〜2027年1月】の間に1回。その後は、四半期に1回程度、または重要な内容を公開するときにご相談させていただければ幸いです（継続するかは、初回のあとにあらためてご相談します）。

## 3. お願いしたい約束ごと

1. **守秘**：公開前の資料は、外部に出さないでください。
2. **個別相談への対応**：アプリや SNS を通じて、飼い主さんから個別の猫について相談を受けることはありません。もし先生に直接ご相談が届いた場合も、このアプリの確認者として個別の相談に応じることはご遠慮ください（「かかりつけの獣医師にご相談ください」とご案内いただけると助かります）。
3. **飼い主さんのデータ**：飼い主さんの記録データを先生にお渡しすることはありません。
4. **お名前の扱い**：お名前を出すかどうかは、先生のご意向に従います（下の欄でお選びください）。
   - お名前を出す場合も、**「確認者」としてのみ** 記載します。「推奨」「おすすめ」「認定」などの言葉は使いません。
   - **ご勤務先の病院名は出しません**（病院の広告と受け取られないようにするため）。
   - 先生のコメントを、広告や推薦文として使うことはありません。
   - お名前を出す場合は、謝礼の有無もあわせて記載します。

## 4. 謝礼について（ユーザーが決めてから、どちらか一方を残す）

- **案A（謝礼あり）**：ご確認1回につき【金額】をお支払いします。お名前を出す場合は「運営者からの依頼にもとづく有償の確認」と記載します。
- **案B（謝礼なし）**：大変恐縮ですが、現在は予算がほとんどないため、無償でのご協力をお願いしております。お名前を出す場合は「運営者からの依頼にもとづく確認（無償）」と記載します。
