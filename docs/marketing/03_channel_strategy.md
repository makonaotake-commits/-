## 0. 全体像

| 段階 | 主力チャネル | 補助チャネル |
|---|---|---|
| ローンチ前（今〜第1弾） | **Instagram（獣医師監修の公式）**、事前登録・お知らせ登録の受け皿 | X（お知らせ・やりとり）、LP |
| ローンチ時 | Instagram、**App Store / Google Play（ASO）**、猫の日（2/22）・世界腎臓デー（2027/3/11） | プレスリリース、ペット系メディア |
| ローンチ後 | ASO＋検索（SEO）、口コミ・紹介 | 動物病院へのチラシ（連携なし）、協賛パートナーのチャネル（広告方針の決定後） |

**予算がない前提でも回る順**：Instagram（自前）→ ASO（自前）→ SEO（自前）→ 動物病院へのチラシ（少額）→ 有料広告（最後）。
※ マーケ予算・体制は未確認です【要確認】（→ `05` §4）。

**全チャネル共通の文言ルール**：社外向けの文面（投稿・ストア・LP・チラシ・プレスリリース・協賛の提案書）では「長く」「長生き」を使わない（`02` §5、ロシアンの要件レビュー #20）。

## 1. SNS

### 1-1. Instagram（主力）

| 項目 | 方針 |
|---|---|
| 役割 | 認知と信頼づくり。S1（診断直後）が検索・保存して見返す「図解の置き場所」 |
| 頻度・体制 | 週2〜3本。図解カルーセルが中心で、ときどきリール。**承認済みの投稿だけを予約投稿**（作成：スコティ → ロシアン → 監修獣医師 → 予約公開）。kickoff #9 |
| 内容の柱（案） | ① 在宅ケアの工夫（補液・投薬の「準備・環境・気持ち」。手技の指導はしない）② 記録のコツ（何を見ておくと獣医師に伝えやすいか）③ よくある誤解を整理する Q&A（AIM など。研究・承認の状況は **投稿ごとに一次情報で確認し、出典と日付を明記**。製品名・購入先は出さず、「期待」「画期的」などの言葉を使わない。ロシアン #19）④ 飼い主さんの気持ちに寄り添う（低い頻度で丁寧に）⑤ 猫の日常＋ひとこと |
| 比率の目安 | ①②で 6割、③で 2割、④⑤で 2割【推測：反応を見て調整】 |
| アプリへの誘導 | リリース前は「準備中・お知らせ登録」まで。リリース後もアプリの宣伝は **5本に1本程度** に抑える【推測】。情報の置き場所としての信頼を優先する |
| やらないこと | 闘病中・亡くなった猫の写真を、許諾なく使う（ロシアン D-7）。個別相談への回答（C-2）。恐怖をあおる冒頭文 |

### 1-2. X（補助）

- 役割：お知らせ、季節のひとこと、投稿の再配信。ニュース（AIM など）への誤解をやわらかく整理する。
- 注意：拡散力がある分、炎上リスクもある。**新薬・フードの効果の話題には反応しない** ことを基本にする。リプライでの個別相談は C-2 の定型文で返す。
- 頻度：Instagram の投稿に合わせて週2〜3回。人手が足りなければ **リリースまで開設を見送ってもよい**。

### 1-3. YouTube・TikTok（第2弾以降）

- 補液の「準備と環境づくり」の動画は需要があると見られる（`docs/sns/trends` の仮説）。ただし、手技の動画は個別指導と受け取られるリスクがあり、制作コストもかかる。
- **第1弾の時期には着手しない**。Instagram のリールの反応を見てから判断する。

## 2. App Store / Google Play（ASO）

| 項目 | 方針（案） |
|---|---|
| カテゴリ | 「ライフスタイル」（ペットの記録アプリとして実態に合うため）。医療機器プログラムに当たるかは、カテゴリではなく機能と表示で決まる。根拠は「判定をしない機能」と説明文の決まり文句に置く（ロシアン #14） |
| タイトルとサブタイトル（案） | 【アプリ名】- 猫の腎臓病ケア記録／サブタイトル：「補液・お薬・体調を、獣医師に伝えやすいかたちに」（ロシアン #3） |
| キーワード候補 | 猫 腎臓病、猫 CKD、皮下輸液、補液 記録、猫 投薬 記録、シニア猫、多頭飼い、ペット 健康記録 |
| 使わない言葉 | 診断、治療、改善、予防、早期発見、悪化を防ぐ、長生き、安心（断定）、獣医師推奨（ロシアン A-6・#15）。禁止語リスト（NFR-TONE-06）ができたら一本化する |
| スクリーンショット | ① ワンタップの「やった」 ② 多頭飼い ③ レポート（PDF）④ 見送りモードには触れず、「通知は控えめ・お休みできる」 ⑤ 開示文（獣医師が運営、データの扱い） |
| 説明文の決まり文句 | 「本アプリは記録のためのアプリで、診断・治療を行うものではありません。治療・食事・補液・投薬は、かかりつけの獣医師の指示を優先してください。」 |
| レビュー依頼 | **見送りモードの猫がいるユーザーには、レビューを依頼しない**。レポートを作った直後など「うまくいった」瞬間に限る（NFR-TONE に合わせる） |
| プライバシー申告 | 実際の動作と一致させる（06 のリリース条件）。第三者の広告 SDK を使わなければ申告が簡潔になる |

## 3. SEO・オウンドメディア（第1弾と並行して小さく始める）

- **前提**：アプリ内の読みもの（F-19）は未定。ここでは **LP に付属する記事ページ** を想定する。
- ねらうキーワード（例）：「猫 皮下輸液 自宅 準備」「猫 投薬 嫌がる 工夫」「猫 腎臓病 記録 何を」「猫 飲水量 測り方」「猫 腎臓病 診察 伝え方」
- **避ける領域**：「猫 腎臓病 ステージ ◯ 余命」「数値の判定」「療法食の比較・おすすめ」。判定・推奨にあたり、ロシアン A-5 にもかかる。広告主との中立性の観点でも避ける。
- 記事の形：出典（IRIS・ISFM など）・監修者・最終更新日を記載する。個別の指示にしない（ロシアン A-5）。
- 量の目安：リリースまでに 5〜8本、その後は月2本程度【推測】。Instagram の図解を文章化して使い回す。
- 獣医療法の広告制限：運営者が動物病院に関わっている場合、病院の宣伝にしない（ロシアン C-3。**ユーザーに確認**）。

## 4. 動物病院・獣医師・動物看護師（B2B2C の準備）

第1弾は **データ連携をしない**（kickoff #4）。そのうえで、次のような「軽い接点」を作る。

| 施策 | 内容 | 時期 | 注意 |
|---|---|---|---|
| 監修獣医師（ユーザー）の人脈で試用をお願いする | 知り合いの獣医師・動物看護師に、レポートの見本を見てもらう。「診察で役立つか」の意見を集める | リリース前（6〜10週目） | 意見の収集までにとどめる。**第1弾では、獣医師の推薦文・コメントを宣伝に使わない**。将来使う場合は §5-2 のルールに従う（ロシアン #16） |
| 院内に置くチラシ・ポスター | 「在宅ケアの記録にどうぞ」。QR コードからストアへ | リリース後 | ①運営者名と決まり文句（「本アプリは記録のためのアプリで、診断・治療を行うものではありません」）を入れる。②「◯◯動物病院おすすめ」「当院推奨」などは書かず、病院のロゴも載せない。③置いてもらう対価・紹介料は **払わない（推奨。ユーザーの確認シートで確認中）**。払う場合は弁護士に確認する。④チラシはロシアン → 監修獣医師の確認を通す（ロシアン #17） |
| 獣医師向けの説明ページ | レポートの見方、アプリがしないこと（判定・提案）の説明 | リリース時 | — |
| 学会・勉強会での紹介 | 監修獣医師が参加する機会に、資料を配る | 第2弾以降 | 学会ごとのルールに従う |

**KPI**：「獣医師に見せた」ことは計測できないため、レポートの作成数（K-5）と、任意のアンケート（「診察で見せましたか？」）で代わりに測る（→ `04`）。

## 5. 飼い主さんのコミュニティ・インフルエンサー・メディア

| 対象 | 施策 | 注意 |
|---|---|---|
| CKD の猫の飼い主さん（ブログ・Instagram で闘病記録を発信している人） | リリース前の試用（ベータ）への招待。意見を聞く | ベータの無償提供・ギフトも「便宜」として扱う。紹介投稿をしてもらう場合は「PR」表示が必須（ステマ規制。ロシアン D-4・#18）。効果の体験談は書いてもらわない。§5-2 のルールに従う |
| 猫系インフルエンサー | ローンチ時の紹介（第1弾ではなくても可） | 同上（§5-2）。闘病を「映え」に使わない人を選ぶ |
| ペット系メディア | ローンチ時のプレスリリース（猫の日・世界腎臓デーに合わせる） | リリース文はロシアンのレビューを通す |
| 保護猫団体 | シニア猫の譲渡先へのお知らせ（第2弾以降） | 団体の方針を尊重する |

### 5-2. 体験談・推薦・引用のルール（ロシアン #16・#18）

| # | ルール |
|---|---|
| 1 | 公式アカウントで引用・リポストできるのは、**使い勝手の感想**（記録しやすい、レポートが便利など）だけ。猫の体調・検査値の変化や「元気になった」などに触れた投稿は、自発的なものでも引用しない（引用した時点で運営者の広告になるため） |
| 2 | 引用・リポストには本人の許諾を取る。写真の利用許諾は別に取る（初期リスク D-7） |
| 3 | ベータ版の無償提供・ギフト・謝礼は「便宜」として扱う。それを受けた人が紹介投稿をする場合は「PR」を付けてもらう |
| 4 | 闘病中・亡くなった猫の写真は、飼い主さんの明示的な希望があるときだけ使う |
| 5 | ストアのレビューを、謝礼や特典と引き換えに依頼しない |
| 6 | 獣医師の推薦文・コメントは、第1弾では宣伝に使わない。将来使う場合は、①本人の書面の同意、②対価・便宜の有無の開示（あれば「PR」）、③内容は使い勝手の感想に限り、猫の健康への効果に触れない、④「獣医師◯名が推奨」のような人数表示や権威づけをしない |
| 7 | 引用する前に、引用する投稿一式をロシアン → 監修獣医師の確認に回す |

## 6. 協賛パートナーのチャネル（広告方針の決定後）

`01` §4 の結論にもとづく。**広告の時期が未決のため、2ケースを示す。**

| 項目 | ケース A：第1弾は広告なし | ケース B：第1弾から「協賛・広告」タブ |
|---|---|---|
| メーカーとの最初の接点 | リリース後 2〜3か月の利用データ（継続率・レポート作成数）をもとに、**第2弾の協賛を提案** | リリース前から協賛の営業が必要（3か月の開発と並行。負担が大きい） |
| 協賛の形 | 啓発コンテンツへの協賛／「サポート企業」掲載 | 同左。商品広告をするなら総合栄養食・シニア食から（療法食は Q で決定） |
| メーカーのチャネルの活用 | 協賛が決まったら、メーカーの飼い主向けサイトやメールでアプリを紹介してもらう可能性【推測：相手次第】。①紹介文はメーカーの広告として扱い、ロシアンのレビューを通す。②「◯◯社推奨」「公認」などの表示はしない。③紹介経由のユーザーの情報はメーカーに渡さない（計測は件数だけ）（ロシアン #22） | 同左 |
| 注意 | 協賛企業が決まったら、開示文と協賛企業の一覧を更新する | 同左。広告枠の表示ルール（NFR-ADS）を第1弾の開発に入れる |

## 7. 再勧誘（休眠ユーザーへの働きかけ）のルール

- 記録が途絶えた人への働きかけ（プッシュ通知・メール・レビュー依頼・アンケート）は、**見送り設定のある人には一切送らない**（ロシアンの要件レビュー #14）。
- 見送り設定がない人にも、「記録が途絶えています」のような責める文言は使わない。送る場合も、本人が許可した通知の範囲で、頻度は月1回までにする【推測：ブリショーと仕様を相談】。
- 多頭飼いで一部の猫だけ見送った家庭では、見送った猫の名前を再勧誘の文面に出さない。
- 再勧誘やお知らせを **メールで送る場合は、特定電子メール法上の送信の同意を取ったうえで送る**。送信者名と配信停止のリンクを必ず入れる（ロシアン #20。詳細は `04` §5）。

## 8. 有料広告（後回し）

- 第1弾の時期は **使わない** ことを推奨する。理由：①予算が未確認 ②病気に関わる広告は、プラットフォームの審査や表現の制約が厳しいと見られる【推測】③信頼の土台ができる前に広告で人を集めても、定着しにくい【推測】。
- 第2弾以降に試す場合は、App Store の検索広告（「猫 腎臓病」など、意図がはっきりしたキーワード）から小さく始める。**健康状態にもとづくターゲティングは使わない**。
