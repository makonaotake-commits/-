## 3. 広告の時期によって変わる部分

| 項目 | ケース A：第1弾は広告なし（推奨） | ケース B：第1弾から「おしらせ」タブに広告 |
|---|---|---|
| 開発への影響 | 広告枠（F-20）は第2弾で作る | 第1弾に広告枠と表示ルール（NFR-ADS）が入り、**12 週の範囲がさらに厳しくなる** |
| 協賛の営業 | リリース後 60〜90 日の実績をもとに、2027 年 5 月ごろから提案 | 2026 年 12 月〜 2027 年 1 月に営業が必要（開発・ストア準備と重なる） |
| 収益の開始 | 第2弾（2027 年夏ごろ【推測】） | 第1弾から。ただし利用者が少ないため小さい【推測】 |
| ロシアンの確認範囲 | 第1弾は文言・ストア・SNS が中心 | 広告の文面・表示・開示・契約まで第1弾で確認が必要 |
| 信頼づくり | 「広告なしで始める」ことが評判につながる | 「分けて出す」ことの説明が必要 |

## 4. 予算配分の案

**マーケ予算・体制は未確認です【要確認】**。金額ではなく、比率と優先順位で示します。

| 項目 | ケース「ほぼゼロ予算」 | ケース「少額予算がある」 |
|---|---|---|
| Instagram（制作・予約ツール） | 自前（ツールは無料プラン） | 30%：イラスト素材・ラインアートの制作 |
| LP・記事 | 無料の作成ツールで最小限 | 25%：LP 制作・記事 5〜8本 |
| ベータ・聞き取りの謝礼 | ギフト程度 | 10% |
| 動物病院向けのチラシ | 印刷のみ（少部数） | 10% |
| プレスリリース配信 | 自前でメディアに案内 | 10%：配信サービス |
| 有料広告（ストアの検索広告） | 使わない | 10%：第2弾以降に試す |
| 予備 | — | 5% |

※ 薬機法・景品表示法・個人情報などの **法務の確認費用** は、マーケ予算とは別に確保することを推奨します（ロシアンの確認は法的な最終判断ではないため）。

## 5. リスクと対策

| リスク | 対策 |
|---|---|
| 開発が遅れて、猫の日に間に合わない | 猫の日を「事前登録のお知らせ」に切り替える。世界腎臓デーをリリースの山にする |
| 投稿の承認待ちで、週2〜3本を維持できない | 2 週間分を先にためておく。レビューの締め切りを決める（スコティ・ロシアンと相談） |
| ローンチ時に、ニュース（新薬など）や悲しい出来事が重なる | 予約投稿の一斉停止の手順（ロシアン D-5）を使う |
| 見送った飼い主さんに、再勧誘やレビュー依頼が届く | 見送り設定のある人を、すべての再勧誘・アンケート・レビュー依頼の配信対象から外す（`03` §7、`04` §0） |
| 闘病中の飼い主さんから個別相談が殺到する | 定型文（ロシアン C-2）を、ローンチ前に用意する |
