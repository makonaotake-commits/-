## 方針

| 項目 | 内容 |
|---|---|
| 本数 | 週2本（火・金）＋ときどきストーリーズ。12月はフィードに 9本 |
| 獲得（S1 診断直後） | ② 診断直後、① 冬の水分補給、③ AIM 薬の現状 で入口をつくる |
| 継続（S2 在宅ケア中） | 補液・投薬・記録・年末年始の休診の備え |
| 看取り・ペットロス | **12月は扱わない。** S4 は獲得の対象にしないため（02 §1）。トーンのルールとロシアンの #13 が固まってから、静かに始める |
| 使わない言葉 | 「長く」「長生き」「少しでも長く一緒に」（ロシアンの #20）、「手遅れ」「放置すると」「◯割の猫が」（02 §5） |
| 出典のない数値 | 使わない。飲水量の「正常値」も出さない（トレンドレポート §5） |
| コア・メッセージ | **「腎臓病の猫との毎日を、ゆっくり記録する。」**（ユーザー決定：マーケ確認シート）。投稿の言葉づかいもこれに合わせ、「ゆっくり」「急がなくていい」を基調にする |
| アプリへの導線 | リリース前は **Google Play の事前登録だけ**（ユーザー決定）。iPhone の方には「リリースはこのアカウントでお知らせします」と案内する。12月は売り込まず、導線はプロフィールのリンクに置くだけ |
| 制作体制 | 画像は **ユーザー本人が Canva で作る**。予算はほぼゼロ。各投稿に「Canva での作り方」を付ける。本数は週2本を基本にし、週3本を上限にする |
| 体験談・UGC | 公式で紹介するのは **使い勝手の感想だけ**。猫の体調・検査値の変化には触れない。本人の許可と写真の許可は別々に取る（ロシアンのマーケレビュー #18） |
| 避ける言い方 | 「これだけ見ておけば大丈夫」のように、記録項目だけ見ていれば十分と読める表現（マーケレビュー #1）。記録の話は「よく記録される項目」「何を記録するかは、かかりつけの獣医師と相談しながら」と書く |
