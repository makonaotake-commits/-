# コメント・DM・質問箱の返信テンプレート（案）

- ステータス：`compliance_reviewed`（ロシアン 2026-11-11。【要確認】の窓口は確認できるまで送らない。次は監修獣医師〔ユーザー〕の確認）
- 作成：スコティ／2026-11-11
- きっかけ：ロシアン「Instagram 12月分レビュー」C-2・C-3（`docs/compliance/review_2026-11-09_instagram_dec.md`）。**アカウント開設の条件**になっています。
- 前提：`CLAUDE.md`、`design_direction.md` §6（ペットロスのトーン）、`calendar_2026-12.md`

---

## 0. 基本のルール

| ルール | 理由 |
|---|---|
| **個別の猫の状態の判断・診断・治療の提案はしない**（数値の評価、ステージ、薬や補液の量、受診すべきかどうかの判断） | 獣医師法（無診察での診療の禁止など）。運営者が獣医師であっても、SNS 上では診察をしない |
| **安心させる言葉も判断にあたるので使わない**（例：「様子を見て大丈夫」「心配ないと思います」「よくあることです」「その数値なら問題ない」） | 善意の言葉でも、個別の猫の状態についての判定になる（ロシアン R-1） |
| 詳しい症状や検査値を **こちらから聞かない** | 聞くと個別相談の流れになる。個人情報が増える |
| 返信は短く、あたたかく。決まり文句でも、最初の一文は相手の言葉を受け止める | 冷たく突き放されたと感じさせない |
| 「長く」「長生き」「治る」「良くなる」「手遅れ」「虹の橋」は使わない | ロシアンの要件レビュー #13・#20、02 §5 |
| 特定の製品名・病院名・購入先は出さない | 中立性。承認前の医薬品の広告にあたるおそれ（AIM など） |
| 返信するのはユーザー（監修獣医師）。テンプレートにない内容は、その場で返さずに保留する | 判断のぶれを防ぐ |
| 個人や猫が特定される情報（地名・病院名・猫の写真つきの病状）がコメントにあったら、非表示にしたうえで、DM でその理由をやさしく伝える | プライバシー |

`【】` の部分は、状況に合わせて入れ替えます。

## 1. コメント・DM の返信

### T-1 個別の相談（コメント欄）
```
コメントありがとうございます。【うちの子のことを思うと、心配になりますよね】。
個別の猫ちゃんの状態については、このアカウントではお答えできないため、かかりつけの先生にご相談ください🐾
```

### T-2 個別の相談（DM）
```
メッセージありがとうございます。
【ご心配な気持ち、お察しします】。

このアカウントは一般的な情報をお届けするためのもので、個別の猫ちゃんの状態についてのご相談にはお答えできません。
かかりつけの先生に、今日のメッセージの内容をそのまま伝えてみてください。

急に様子が変わったときは、記録より先に、かかりつけの動物病院にご相談ください。
```

### T-3 急ぎに見える相談（「ぐったりしている」「何も食べない」など）
**すぐに返します。** 症状の重さは判断しません。
```
メッセージありがとうございます。
このアカウントでは、猫ちゃんの状態を判断することができません。
いつもと様子がちがって心配なときは、すぐに、かかりつけの動物病院にご連絡ください。
休診の時間であれば、かかりつけの先生から案内されている連絡先にご相談ください。
```
- 特定の夜間救急病院の名前は出しません（ロシアン C-5）。

### T-4 検査値を書いて「大丈夫ですか？」と聞かれた
```
数値を見ると、気持ちが落ち着かなくなりますよね。
検査の結果は、ほかの検査や猫ちゃんの様子とあわせて見るものなので、このアカウントでは良い・悪いをお伝えすることができません。
次の診察で、かかりつけの先生に「この数値はどう考えればいいですか？」と聞いてみてください。
```

### T-5 補液・お薬の量や回数、やめてよいかを聞かれた
```
毎日のケア、本当におつかれさまです。
補液やお薬の量・回数は、猫ちゃんの状態を診ているかかりつけの先生が決めるものなので、このアカウントではお答えできません。
変えたい・やめたいと感じたときは、自己判断で変えずに、まず先生に相談してみてください。
```

### T-6 特定のフード・サプリ・新しい薬（AIM など）について聞かれた
```
気になりますよね。
このアカウントでは、特定の商品についてのご案内はしていません。
今の治療やごはんとの組み合わせも含めて、使う前にかかりつけの先生に相談してみてください。
```
- AIM の薬については、「承認の状況は、【確認した日】時点で発表されていません」以上のことは書きません（ロシアン I-1〜I-4）。

### T-7 感謝・共感のコメント
```
うれしいお言葉、ありがとうございます。【うちの子】との毎日が、少しでも穏やかでありますように🐾
```
- 「うちの子と少しでも長く」とは書きません。

### T-8 悲しみ・お別れのコメント
決まり文句ではなく、短く。アプリやほかの投稿の案内はしません。
```
大切なお話を聞かせてくださって、ありがとうございます。
【◯◯ちゃん】は、たくさんの想いに包まれていたのだと思います。
```
- 相手が使っている言葉（「お空」「虹の橋」など）には合わせてかまいません。こちらから使うのは避けます。
- 「もっと早く」「〜していれば」に、こちらから触れません。

### T-9 自分を強く責めている・とてもつらそうなコメントや DM
```
そんなふうに感じてしまうほど、【◯◯ちゃん】のことを大切に思っていらっしゃるのだと思います。
【◯◯ちゃん】と一緒に過ごしてきた時間と、その想いは、きっと伝わっていたと思います。

つらさが続くときは、ひとりで抱えずに、身近な人や相談できる窓口に話してみてください。
【ペットロスの相談先：要確認】
```
- 2行目はロシアンの例文です（R-2）。最終的な文言は監修獣医師と決めます。
- 安楽死・治療の中止など、**飼い主さんの個別の選択には触れません**。直接聞かれた場合も評価はせず、T-8 に近い受け止めの言葉だけを返します。
- 【ペットロスの相談先】は、非営利・公的なものを優先して探します。実在していて、今も受け付けていることを確かめるまでは【要確認】のままにし、その行は消して送ります。
- 命の危険をうかがわせる言葉があるときは、T-9 ではなく **T-9b** を使います。

### T-9b 命の危険をうかがわせる言葉があるとき（「もう生きていたくない」など）
**見つけたらすぐに返します。** 受け止めの一文と、公的な相談窓口の案内だけにします。ペットや病気の話題には広げません。
```
つらい気持ちを話してくださって、ありがとうございます。
今のお気持ちを、ひとりで抱えないでください。
国（厚生労働省）が案内している相談窓口で、電話やSNSで話を聞いてもらえます。
・厚生労働省「まもろうよ こころ」 https://www.mhlw.go.jp/mamorouyokokoro/
【電話窓口の名前と番号：要確認】
```
- 案内するのは、**公的機関が案内している窓口だけ**です（ロシアン R-3）。
- 「まもろうよ こころ」は、厚生労働省が相談窓口を案内している公式ページです。2026-11-11 にスコティが Web 検索で、ページがあることと、電話窓口の一覧のページ（https://www.mhlw.go.jp/mamorouyokokoro/soudan/tel）があることを確認しました。中身（番号・受付時間）はページを開いて確認できていません。
- 電話窓口の候補（**要確認**。公開の前に、上の厚生労働省のページで番号と受付時間を確認してから載せる）：
  - こころの健康相談統一ダイヤル（自治体の相談窓口につながる）
  - いのちの電話（日本いのちの電話連盟）
  - よりそいホットライン
  - 検索結果（自治体が配っている一覧 PDF の転載）には番号や受付時間も載っていたが、二次情報なのでここには書かない。
- 夜間や休止中でも DM の自動返信（T-14）は届く。T-9b の言葉を見つけたら、ユーザーが気づいた時点ですぐに返す。
- 対応したことは記録に残す（日時・返信した内容。相手の名前は記録しない）。

### T-10 誤った情報を含むコメント（例：猫に危ない食べもの・植物をすすめている）
```
コメントありがとうございます。
【ユリ】は猫にとって危険な植物とされているため、念のためお知らせさせてください。気になることがあれば、かかりつけの先生にご相談ください。
```
- 言い争いはしません。

#### 非表示にするかどうかの基準（ロシアン R-4）
| 非表示にする | 非表示にしない |
|---|---|
| ① 猫に有害なもの（植物・食べもの・人の薬など）をすすめている | 意見の違い |
| ② 治療・補液・投薬を自己判断でやめる・変えるようすすめている | アカウントや投稿への批判 |
| ③ 特定の商品に、病気への効き目があるとうたっている | 自分の猫の経験を話しているだけのコメント（①〜⑤にあたらないもの） |
| ④ 個人や猫が特定される情報（地名・病院名・連絡先など） | |
| ⑤ 誹謗中傷 | |

- ①〜③は、ほかの人のために、T-10 の返信をしてから非表示にする。④は非表示にしてから、DM で理由をやさしく伝える。⑤は返信しない。
- **非表示にしたものは記録に残す**：日時、投稿、どの基準（①〜⑤）にあたったか、返信したかどうか。記録の置き場所はユーザーと決める（リポジトリには個人情報を置かない）。
- 根拠を示すときは一次情報の出典を使います。

### T-11 批判・ご意見
```
ご意見ありがとうございます。いただいた内容は、今後の発信の参考にさせていただきます。
```
- 事実の誤りを指摘された場合は、ユーザーとロシアンが確認し、必要なら投稿を訂正します。

### T-12 広告・PR・取材の依頼（DM）
```
ご連絡ありがとうございます。担当者から改めてご返信いたします。
```
- 中身の判断はユーザーが行います。
- **広告の方針（NFR-ADS-09・10）が決まるまでは、商品の提供や有償の依頼は受けません**（ロシアン R-5）。取材は受けてよいですが、話す内容は投稿と同じく、獣医師法・中立性のルールに従います。
- 広告を始めたあとの PR 投稿は、ロシアンのレビューを通し、「PR」「広告」と表示します。

### T-13 体験談・写真の紹介の許可をお願いするとき
```
すてきな投稿をありがとうございます。
もしよろしければ、このアカウントで【ご感想】を紹介させていただけないでしょうか。
・ご紹介する文章：【引用する文】
・写真の使用：【使う／使わない】（写真を使う場合は、別にお許しをいただきたいです）
お断りいただいても、まったく問題ありません。
あとから取り下げたくなった場合も、いつでもご連絡ください。
```
- 許可のやりとり（DM）は保存しておきます（ロシアン R-6）。
- 紹介するのは **使い勝手の感想だけ** です。猫の体調・検査値の変化には触れません（ロシアン マーケレビュー #18）。
- 文章の許可と、写真の許可は **別々に** もらいます。
- 闘病中や亡くなった猫の写真は、飼い主さんがはっきり希望したときだけ使います。

## 2. 自動返信・休止中の案内

### T-14 DM の自動返信（いつも）
```
メッセージありがとうございます。
このアカウントでは、個別の猫ちゃんの状態についてのご相談にはお答えできません。個別のご相談には、お返事ができないこともあります。
急に様子が変わったときは、かかりつけの動物病院にご相談ください。
```

### T-15 年末年始など、投稿とお返事を休むとき（例：12/30〜1/3）
```
メッセージありがとうございます。
【12月30日〜1月3日】はお休みをいただいており、お返事は【1月4日】以降になります。
急に様子が変わったときは、かかりつけの動物病院、または先生から案内されている休診中の連絡先にご相談ください。
```
- Instagram（Meta Business Suite）の自動返信機能で、どこまで設定できるかは開設前に確認します（推測：プロアカウントのクイック返信・自動返信が使える）。

## 3. 質問箱（ストーリーズ）

### T-16 質問箱の画面に入れる文
```
CKDのケアで、知りたいことを教えてください🐾
※個別の猫ちゃんのご相談（検査値・症状・お薬の量など）にはお答えできません
```

### 取り上げるときのルール（ロシアン C-3）
1. 一般的な情報で答えられる質問だけを選ぶ。
2. 質問の文は、個人や猫が特定されないよう要約してから載せる（スクリーンショットをそのまま使わない）。
3. 回答の文面も、公開前にロシアン → 監修獣医師の確認を通す。
4. 個別の相談だった質問には、取り上げずに T-2 の DM を送る（返信するかどうかはユーザーが判断）。

## ロシアンに見てほしい点
1. T-3 で「すぐに、かかりつけの動物病院に」と書くことが、受診の判断（判定）にあたらないか。
2. T-9 の「どの選択も、うちの子を想って選んだものです」が、個別の選択（安楽死など）の評価に読めないか。
3. T-10 で、危険な情報を訂正するときの書き方と、非表示にする基準。

## ユーザー（監修獣医師）に決めてほしい点
1. DM の返信は、全部ユーザーが手で返すか、T-14 の自動返信を使うか。
2. T-9 のペットロスの相談先と、T-9b の電話窓口（スコティが公式の情報で調べ、ロシアンが確認する形でよいか）。
3. 返信までの目安の時間を、プロフィールや自動返信に書くか（書かないのがスコティのおすすめ。約束できないため）。
