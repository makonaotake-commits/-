# Instagram デザインの方向性（案）

> **2026-11-11 引き継ぎ**：配色・フォント・猫の描き方・Canva テンプレートの設計は、デザイン担当の **ペルシャ** に引き継ぎました（ブランド全体として決め直すため）。ペルシャの案が決まるまでは、ユーザーが選んだ **ミルクティー（案1）／Zen Maru Gothic＋BIZ UDPGothic／いろんな猫＋小さな案内役アイコン** を仮の前提にします。
> このファイルで引き続きスコティが持つのは、**§6 看取り・ペットロスのトーンのルール** と、投稿の構成（§5 のカルーセル・リールの型）です。予約投稿を止める担当は **ユーザー本人**（決定）。

- ステータス：`draft`（ロシアンのレビュー前）
- 作成：スコティ／2026-11-09
- 前提：`CLAUDE.md`、`.claude/agents/scoty.md`、`docs/kickoff_answers.md`（自由記入：「ペットロスへの配慮が何より大事。親しみやすくも信頼感のあるシンプルなラインアートのデザイン。安心感があって、せかせかしていない、余裕のあるデザインと UX」）

## 1. コンセプト

**「日だまりのような、静かな信頼」**

| 大事にすること | 具体的には |
|---|---|
| ゆとり | 余白を多めにとる。1枚に詰め込まない。文字は少なく |
| やわらかさ | 角の丸い線。真っ黒ではなく、あたたかい焦げ茶色で描く |
| 信頼 | 色数をしぼる。図解は正確に。出典を必ず小さく入れる |
| 怖がらせない | 赤い警告色や「危険！」のような強い見出しは使わない |

## 2. 配色（3案）

どの案も、**本文の文字は「インク色」をベース色の上に置く**のが前提です。メインカラーの上に白い文字は置きません（読みづらくなるため）。
コントラスト比の値は目安です。デザイン用のファイルを作るときに、ツールで実際に確認します。

### 案1「ミルクティー」（おすすめ）
| 役割 | 色 | HEX |
|---|---|---|
| ベース（背景） | あたたかい生成り | `#FAF6F0` |
| インク（線・文字） | 焦げ茶 | `#4A4038` |
| メイン | セージグリーン | `#8FB5A8` |
| アクセント | 淡いピーチ | `#E8B4A0` |
| サブ | ベージュ | `#D9C9B6` |

- 印象：あたたかく、落ち着いていて、医療っぽさが強すぎない。
- グリーンは「穏やかさ」の色として使います。数値がよい・悪いの意味は持たせません。

### 案2「やわらかな空」
| 役割 | 色 | HEX |
|---|---|---|
| ベース | ほんのり青みのある白 | `#F7F8FA` |
| インク | グレーがかった紺 | `#3E4552` |
| メイン | くすんだ水色 | `#9BB7D4` |
| アクセント | アプリコット | `#F2C48D` |
| サブ | 淡いミント | `#C9D6CF` |

- 印象：清潔感があり、信頼感が強い。少しクールに見える。

### 案3「ひだまり」
| 役割 | 色 | HEX |
|---|---|---|
| ベース | クリーム | `#FFF9EE` |
| インク | 焦げ茶 | `#5A4A3A` |
| メイン | はちみつ色 | `#E6B980` |
| アクセント | 若草色 | `#A7C4A0` |
| サブ | 薄いベージュ | `#EFE3D0` |

- 印象：いちばんあたたかく、親しみやすい。情報の投稿では少し甘く見えるかもしれない。

### 配色のルール（どの案でも共通）
- **検査値を信号の色（赤・黄・緑）で塗り分けない。** アプリは判定をしない方針なので（kickoff #2）、図解でも「正常／異常」を色で表しません。
- 強調はアクセントカラーで 1か所だけにします。ネオンのような強い色は使いません。
- ペットロスの投稿では、メインとアクセントを使わず、ベース・インク・サブの3色だけにします（§6）。

## 3. ラインアートのタッチ

| 項目 | ルール |
|---|---|
| 線 | 太さは一定（1080px 幅の画面で 3〜4px くらい）。線の端は丸くする。少しだけ手描きのゆらぎを残す |
| 線の色 | インク色。真っ黒（`#000`）は使わない |
| 塗り | 基本は線だけ。塗るときはベタ塗りを 1〜2色、面積は小さく。グラデーションや影はつけない |
| 猫 | 丸みのある体。表情はおだやかか、眠っている顔。いろんな毛色や柄、体格の猫を描く（シニア猫らしい痩せた体つきも、悲しそうではなく描く） |
| 描かないもの | 苦しむ・泣く・ぐったりする猫／針を刺す瞬間のアップ・血・注射器を強調した絵／悲しそうなビフォーアフター |
| 補液・投薬の絵 | 道具は記号として小さく描く。猫と飼い主さんが「いっしょにいる」場面にする |
| 植物 | **ユリは絶対に描かない**（猫にとって有毒なため。ユリを置いても大丈夫と誤解させないように）。お花はユリ以外の簡略化した花か、葉だけにする |
| 食べもの | ネギ類・チョコなど、猫に危ないものは描かない |

### マスコット猫について（§7 で選んでほしいこと）
- **案A：看板猫を1匹決める**。毎回同じ猫が案内する形で、覚えてもらいやすい。
- **案B：毎回いろんな猫を描く**。「うちの子に似てる」と思ってもらいやすく、いろんな猫を受け入れる雰囲気になる。
- スコティのおすすめは **B を基本にして、ナビゲーター役の小さな猫アイコンを1つだけ固定する** ことです。

## 4. フォント

ここに挙げたのは、Google Fonts で無料公開されているフォントです（SIL Open Font License とされています。使う前にライセンスをもう一度確認します）。

| 用途 | フォント | 理由 |
|---|---|---|
| 見出し | **Zen Maru Gothic**（Medium〜Bold） | 丸みがあってやさしい。ラインアートとなじむ |
| 本文 | **BIZ UDPGothic**（Regular） | 読みやすさを重視したユニバーサルデザインのフォント。年配の飼い主さんにも読みやすい |
| 数字・単位 | BIZ UDPGothic | 「mg/dL」などを読み間違えにくい |

### 文字のルール
- 1枚あたりの本文は **80字以内** を目安にする。
- 文字の大きさの目安（1080px 幅の画面で）：見出し 64〜80px、本文 36px 以上、出典 24px 以上。
- 1行は 15〜18字くらいで改行する。行間は広め（1.6〜1.8）にとる。
- 「！」は使いすぎない。「必ず」「絶対」「危険」は見出しに使わない。

## 5. 投稿テンプレートの考え方

### 共通
- サイズ：縦長の **1080×1350（4:5）** を基本にします。最近はプロフィールの一覧で縦長に切り取られて表示されると言われているので、大事な要素は中央に寄せます（推測を含むので、運用を始める前に実際の画面で確認します）。
- 余白：上下左右に 80px 以上とる。
- 毎回同じ場所に置くもの：右下にナビゲーターの猫の小さなアイコン、最後の1枚に免責文と出典。

### カルーセル（図解）の型
| 枚目 | 役割 | デザイン |
|---|---|---|
| 1 | フック（表紙） | 大きな見出し1行と猫のラインアート。文字は 20字以内 |
| 2 | 「この投稿でわかること」 | 箇条書き 3つまで |
| 3〜7 | 本文 | 1枚につき言いたいことは1つ。図解は線と、色1色だけ |
| 8 | まとめ | 1枚にまとめる。保存したくなる表やチェックリストにする |
| 9 | 締め | 「迷ったら、かかりつけの先生に」＋免責文＋出典＋保存・フォローの案内（やわらかく） |

- 免責文（固定）：「※一般的な情報です。治療・ごはん・補液の内容は猫ちゃんの状態により異なるため、かかりつけの獣医師にご相談ください。」
- 「獣医師監修」のマークは、ユーザーの確認が済んだ投稿だけに付けます。

### リール
- テンポはゆっくり（1カットあたり 2〜3秒以上）。早送りや激しい切り替えはしない。
- BGM は静かなピアノやアコースティック。効果音で驚かせない。
- 字幕を必ずつける（音なしで見る人も多いため）。点滅する演出は使わない。

### ストーリーズ
- アンケートや質問箱を使うのはよい。ただし、個別の数値や症状の相談には答えず、「かかりつけの先生へ」と案内する決まりの返事を用意しておく。

### 広告・PR 投稿の見分けやすさ
- 収益モデルはフード・療法食メーカーの広告です（kickoff 追加の決定）。PR 投稿は **見た目の型をはっきり変え**、「PR」「広告」をわかりやすく表示します。
- ステルスマーケティング規制（景品表示法の告示）に関わるので、表示のしかたはロシアンに確認します。
- 情報の投稿の中に特定の商品をこっそり入れることはしません。

## 6. 看取り・ペットロスを扱うときのトーンのルール

いちばん大事にしたいところです。この種の投稿は **ほかの投稿よりも優先してロシアンと監修獣医師に確認してもらいます**。

### 6-1. 言葉
| しない | 代わりに |
|---|---|
| 「もっと早く気づいていれば」「〜しなかったから」（飼い主さんのせいだと感じさせる言い方） | 「どの選択も、うちの子を想って選んだものです」 |
| 安楽死・治療をやめる・入院か在宅か、といった選択を良い悪いで評価する | 「選び方に正解はありません。かかりつけの先生と相談しながら決めていいことです」 |
| 「乗り越えよう」「前を向こう」と立ち直りを急かす | 「悲しみのかたちや長さは、人それぞれです」 |
| 「虹の橋」「天使になった」などの表現を決まり文句として使う | 「お別れ」「見送る」など、どんな考えの人にも合う言葉を基本にする（その方の言葉づかいには合わせる） |
| 「いつまで頑張れますか」のような余命を思わせる見出し | 予後の話は一般論にとどめ、「かかりつけの先生と」をはっきり書く |

### 6-2. 見た目
- 使う色はベース・インク・サブの3色だけにする。アクセントカラーは使わない。
- **猫の亡骸を思わせる絵は描かない**（目を閉じて横たわり動かない猫、天使の輪、羽など）。
- 象徴として描くもの：窓辺の日だまり、空いたクッション、お気に入りのおもちゃ、首輪、季節の葉。お花を描く場合も **ユリは描かない**。
- 余白をいつもより多くとり、文字は少なくする。

### 6-3. 投稿の運び方
- **1枚目とキャプションの1行目に、内容をあらかじめ知らせる一文を入れる**（例：「この投稿は、お別れについてのお話です。読みたいときに、そっと開いてください。」）。
- **アプリの宣伝、保存・フォローのお願い、PR を入れない。** ハッシュタグも控えめにする。
- ペットロスの投稿を2回続けない。前後に PR 投稿を置かない。
- 予約投稿で運用するので、**大きな災害やつらいニュースがあったときに、予約した投稿を止める人と手順を決めておく**（ボンベイとユーザーで決める）。

### 6-4. コメント・DM・投稿の紹介（UGC）
- 悲しみのコメントには、決まり文句ではなく短い言葉で返す。返事の例はロシアンのレビューのあとで用意する。
- 体調の悪化や自分を責める言葉が強いコメントには、専門の相談窓口を案内する。**どの窓口を案内するかは、実在していて今も受け付けていることを確かめてから決めます（まだ決めていません）**。
- 亡くなった猫の写真を紹介するときは、必ず飼い主さんの許可を取る。もう一度紹介する前にも、あらためて確認する。
- 命日や記念日に関わる投稿は、本人から希望があったときだけにする。

- ペットロスの投稿で使う「内容をあらかじめ知らせる一文」と「選び方に正解はありません」などの言い回しが、獣医療の情報提供として問題ないか。
