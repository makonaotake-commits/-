## 5. 注意トピック（誤情報・炎上リスク・繊細さ）
| トピック | リスク | 推奨スタンス |
|---|---|---|
| **AIM / FeliAIM** | 「もうすぐ治る薬」「AIM配合フード・サプリで治療できる」という誤解。2026年11月9日時点で **承認の発表は確認できず（研究段階・審査中）**。治験結果も探索的なもの | 「研究段階」と明記し、断定・期待のあおりはしない。最新情報は公式発表で確認 |
| **「15歳の猫の約8割が腎臓病」などの統計** | 出典がはっきりしないまま拡散している数値がある（検索結果の記事タイトルで確認） | 一次情報で確認できるまで使わない |
| **サプリ・漢方・民間療法** | 根拠が少ない（例：漢方系サプリの研究は4匹・対照群なしの予備試験）のに「腎臓にいい」と売られている | 特定の商品に触れない。「使う前に獣医師へ」 |
| **たんぱく質制限の考え方** | 「腎臓病＝たんぱく質を減らす」の一律な理解。メーカー資料でも、初期段階での制限には根拠が乏しいとの記述あり | 食事は個別に獣医師と決める、とだけ伝える |
| **飲水量の"正常値"** | 情報源によって目安が大きく違う（体重1kgあたり40〜50ml〜150mlなど） | 数値は出さず「その子のふだんとの比較・記録」を推奨 |
| **補液・投薬の手技** | SNS の動画で手技をまねると事故やトラブルにつながるおそれ | 手技は病院で直接習う前提。「工夫」は環境・気持ちの面に限る |
| **療法食・フード広告（収益モデルとの関係）** | 法人パートナーが療法食メーカーのため、情報投稿と広告が混ざると中立性を疑われる | 広告は明示し、情報投稿では特定ブランドを推さない（ロシアン・ベンガルに確認） |
| **看取り・ペットロス・闘病投稿** | 「飼い主のせい」「もっと早く気づけば」と読める表現は深く傷つける。安楽死の話題は特に繊細 | 罪悪感をあおらない。コメント欄の運用方針を事前に決める |
| **検査値の解釈** | 「この数値ならステージ◯」と書くと、獣医師法・誤解のリスクがある | 項目の意味の説明だけにとどめる。人間の eGFR 基準と混同しない |
