## 1. 背景

- 慢性腎臓病（CKD）は、シニア猫の多くが向き合う病気とされている（※頻度の具体的な数値は未確認のため記載しない。ベンガルの市場調査で出典つきで補う）。
- 猫の CKD のケアは長期にわたり、飼い主さんが自宅で次のことを続けることが多い。
  - 体調の観察：食欲・飲水・尿・嘔吐・体重・便・元気さ
  - 皮下輸液（補液）：獣医師に指示された量・頻度で行う
  - 投薬：リン吸着剤・降圧薬・制吐剤など。錠剤・粉薬・ペーストなど形もさまざま
  - 通院と、検査値（CRE・SDMA・BUN・P・K・USG・UPC・血圧など）の確認
- 対応は IRIS ステージ・サブステージ・併発疾患によって猫ごとに大きく異なる。そのため、アプリが一律の目標値や治療内容を示すことはできない。

## 1-b. アプリ名
- **ねこと、ゆっくり**（2026-11-12 ユーザー決定。商標などの確認はペルシャが行う）

## 2. 目的

**「うちの子と少しでも長く、穏やかに過ごす」ための毎日の記録を、飼い主さんが無理なく続けられるようにする。**

> これは社内向けの目的です。ストアの説明・LP・SNS など社外向けの文面では「長く」を使いません。アプリの効果（長生きする）をほのめかす表現になりうるためです。社外向けは「穏やかな毎日のための記録」「獣医師に伝えやすく」のように表現します（ロシアン #20）。
その記録を、診察時に獣医師へ短時間で伝えられる形にする。

## 3. 解決する課題（飼い主さん側）

| # | 課題 | アプリでの解決方針 |
|---|---|---|
| P1 | 診断直後は情報が多すぎて不安になり、何を見ればよいか分からない | 記録項目を最初から絞り、やさしい言葉で並べる。判定や「危険」表示はしない |
| P2 | 毎日の観察をメモ・カレンダー・記憶に頼っていて、続かない／診察で思い出せない | ワンタップ記録・前回コピー。診察前に **獣医師に見せるレポート（PDF）** をすぐに作れる |
| P3 | 補液・投薬の「やったかどうか」を家族で確認し合えない、忘れる | 記録とリマインダーを1か所にまとめる（家族共有は第3弾以降） |
| P4 | 多頭飼いで、どの子に何をしたか混ざる | 猫ごとに記録・リマインダー・レポートを分ける |
| P5 | 体調が悪い日や看取りの時期に、アプリの通知や表示がつらくなる | せかさない通知文、猫ごとの通知のお休み・一覧から外す（第1弾 F-10）、見送り・思い出（第2弾 F-25） |

## 4. やらないこと（スコープ外）

決定事項（`kickoff_answers.md` #2）により、**アプリは「記録と見える化」だけを行う**。

- ❌ 入力値からの IRIS ステージ判定、病状の良し悪しの判定、「受診してください」等の判断
- ❌ 補液量・投薬量・療法食の提案や自動設定
- ❌ 検査値への基準範囲・目標ライン・色分け（赤＝悪い等）の自動表示
- ❌ 動物病院とのデータ連携（最初は「レポートを見せるだけ」）

> ⚠️ 上記を将来やる場合は、獣医師法（診療行為）と動物用医療機器プログラムに当たる可能性があるため、ロシアンの確認が必須です。

## 6. 成功指標（KGI / KPI）

> 目標値はベンガルが設定します（Q-12 決定。`docs/marketing/` の KPI を参照）。ここでは「何を測るか」だけを決めます。

### KGI（仮）
- 第1弾リリース後の **継続利用**：記録を続けている飼い主さんの数
- 事業面：広告収益（**第1弾は広告なし**〔Q-02 決定〕。第2弾以降で開始）

### KPI（第1弾で計測するもの）

| ID | 指標 | 定義（仮） | 意図 |
|---|---|---|---|
| K-1 | 初回記録完了率 | インストール後24時間以内に、1件以上の体調記録をした割合 | 診断直後でも迷わず始められるか |
| K-2 | 継続率 | 7日後／30日後に、記録が1件以上ある割合 | 続けやすさ |
| K-3 | 週あたりの記録日数 | 1匹あたり、記録のある日数の中央値 | 習慣化 |
| K-4 | リマインダー完了率 | 補液・投薬リマインダーのうち「やった」が記録された割合 | ケアの抜け漏れ防止 |
| K-5 | レポート作成数 | 1ユーザーあたり月の PDF 作成回数 | 診察での活用 |
| K-6 | 通知の停止・解除率 | 通知をオフにした割合と、その理由（任意回答） | せかしていないかの確認 |

- **測らないもの**：猫の検査値の変化を「アプリの効果」として KPI にしない。効果を示唆する表現につながるためです。

### 計測の注意
- 分析ログには猫の体調データの中身を含めない。件数・操作だけを記録する（→ `05` の NFR-PRV-04）。
- **一覧から外した猫・お休み中の猫（第1弾）、見送りに設定した猫（第2弾）とそのアカウントは、KPI（特に K-2 継続率・K-6 通知停止率）の分母から除く。** 再利用の呼びかけ施策の対象にもしない。K-6 の理由の質問は、見送り設定のある人には出さない（ロシアン #14。ベンガルに申し送り）。
