### 追加・変更の根拠

| # | 変更 | 根拠 |
|---|---|---|
| 1 | **F-10 お休み・一覧から外すを Must に追加**（第3版で、見送り専用の機能は第2弾の F-25 へ移した） | 第1弾にリマインダーがある以上、猫を亡くしたあとも通知が鳴り続けるのを確実に止める手段がないと、ペットロスへの配慮（最重視の要望）に反する。汎用の機能にしたので、開発量は小さい |
| 2 | F-08 振り返り（編集・削除）を追加 | 記録を直せないと、レポートの内容が不正確になる。最低限の確認・修正手段が必要 |
| 3 | F-09 書き出し・削除、F-01 同意を追加 | 個人情報の取り扱い（削除・持ち出し）と、免責の表示のために、リリース時に必須 |
| 4 | F-12 体重グラフを Should に追加 | 体重は第1弾の体調記録に含まれていて、推移は診察で見せたい情報の代表。検査値グラフ（第2弾）と同じ部品を先に作れるため、第2弾の負担も減る（推測） |
| 5 | F-06 リマインダーを明記 | 仮案の「皮下輸液」「投薬」が記録だけか、通知も含むかがあいまいだったため、通知を含むと明記した |
| 6 | 薬の候補リストを入れる（第3版で変更） | ユーザーの決定（Q-09）。推奨と受け取られないための条件と、保守の体制を F-26 に定めた（⚠️） |

### 第1弾に入れないもの
- 療法食・フード量（F-14）、写真（F-15）、検査値（F-16）、本格的な通院予定（F-17）→ **第2弾**
- 家族共有（F-18）→ **第3弾以降**
- 見送り・思い出（F-25）→ **第2弾**（Q-11 決定）
- 広告枠（F-20）→ **第2弾以降**（Q-02 決定：第1弾は広告なし）。出す弾では「協賛・広告」タブ・掲載基準・審査の流れ（NFR-ADS-09・10）をリリース条件に入れる
- 学習コンテンツ（F-19）→ 未定
- 動物病院との連携（F-21）、判定・提案（F-22）→ **作らない**

### 規模感についての注意（推測）
- 上記は、ユーザー本人が中心となって3か月で両 OS に出すには **余裕のない範囲** と見ています（推測）。候補リスト（F-26）の作成も加わりました。
- 削る順番の案：① F-13 通院日メモ → ② F-24 通知の内容を隠す → ③ F-12 体重グラフ（PDF の一覧表だけにする） → ④ CSV の書き出し（全削除は残す） → ⑤ 薬の候補リストの収録数を絞る（自由入力は残す）
- **F-10 お休み・一覧から外す、F-01 免責・同意は削らない** でください。

## 4. リリース計画（仮）

> 開発は **ユーザー本人がこのリポジトリで行う** 前提です（Q-13 決定）。期間はすべて **仮** で、技術選定（`07` の Q-22）のあとに見直します。
> 監修獣医師・運営者・開発者をユーザー1人が兼ねるため、**「決める・確認する」作業を前半に寄せ、後半は開発に集中できるようにする** 計画にしています。

| 時期（目安） | 内容 | 担当 |
|---|---|---|
| 1週目 | **技術選定（Q-22）**、開発環境とリポジトリの構成、ストアの開発者登録（Apple・Google） | ユーザー |
| 1〜2週目 | 未決の値の決定（Q-08v・Q-19v・Q-23v・Q-24）、Q-11b の再確認、第3版の差分のロシアンレビュー | ユーザー、ロシアン、ブリショー |
| 1〜3週目 | 薬の候補リストの初版（F-26）：ブリショーが案 → ユーザー確認 → ロシアン | ブリショー、ユーザー、ロシアン |
| 2〜3週目 | 画面のラフとトーン（ラインアート）。デザインを誰が作るかは未決（→ `07` の Q-26） | ユーザー（＋デザイン担当） |
| 3〜9週目 | 第1弾の開発。順番の案：データ保存と猫の登録 → 体調記録 → 補液・投薬・リマインダー → 振り返り → レポート PDF → お休み・一覧から外す → 設定 → 候補リストの組み込み | ユーザー |
| 6〜10週目 | 文言の最終レビュー（画面・通知・PDF・ストアの説明文・プライバシーポリシー・利用規約） | ロシアン、ユーザー |
| 9〜11週目 | テスト（多頭飼い・お休みと一覧から外す・オフライン・文字サイズ特大・二重投与の表示）、飼い主さん数名による試用（仮） | ユーザー |
| 11〜12週目 | ストア申請と審査対応（審査期間には余裕を見る） | ユーザー |
| 12週目まで | **第1弾リリース** | — |
| 第1弾の後 | KPI の確認 → 第2弾の要件の詳細化。F-16 検査値・F-14 フード・F-25 見送り・F-20 広告は、着手前にロシアンが再レビュー | ブリショー、ベンガル、ロシアン |

### 第1弾のリリース条件（Definition of Done・仮）
- [ ] 第1弾の Must 機能が、iPhone と Android の両方で動く
- [ ] 飼い主向けの全文言が `compliance_reviewed` になっている
- [ ] ⚠️ の付いた機能（F-04, F-05, F-07, F-12, F-26）について、ロシアンの確認が終わっている
- [ ] 薬の候補リスト（F-26）の中身を監修獣医師が確認し、ロシアンがレビューした。リストの版・更新日・出典と、出典の利用条件の確認結果が記録されている
- [ ] 「お休み」「一覧から外す」で、その猫の通知がすべて止まることをテストで確認した。再利用の呼びかけ・アンケート・記念日の通知を出す仕組みがないことを確認した
- [ ] レポートで「記録なし（—）」と「0回」が区別され、集計値に記録日数が並んでいる
- [ ] F-01・プライバシーポリシー・ストアのプライバシー申告で、データの扱い（Q-03）の表現が一致している
- [ ] 開示（監修者・運営者・収益源〔「将来、広告を掲載する予定」〕・監修の範囲）がアプリ内とストアの説明文に載っている
- [ ] SDK 一覧（NFR-PRV-05）があり、プライバシーポリシー・ストアのプライバシー申告（「広告なし」を含む）と一致している。記録の内容が分析・クラッシュ報告に含まれないことを確認した
- [ ] 「お休み」を期間つきで設定し、期間が終わっても通知が自動で再開しないこと、終了のプッシュ通知が出ないこと、アプリを開いたときに画面の中だけで「再開する／このまま止めておく／一覧から外す」が同じ大きさで出ることをテストで確認した
- [ ] 文字サイズ「特大」で、主要画面の表示が崩れない
- [ ] プライバシーポリシー・利用規約・ストアのプライバシー申告が、実際の動作と一致している
