## ペルソナ A：診断されたばかりで不安な飼い主さん（メイン）

| 項目 | 内容 |
|---|---|
| 名前 | 佐藤 みのり（仮）・40代・会社員・一人暮らし |
| 猫 | 「むぎ」14歳・メス。健康診断で CKD と言われたばかり |
| 状況 | 療法食への切り替えと、次回の再検査をすすめられた。ネットで調べるほど不安になる |
| 気持ち | 「私が気づくのが遅かったのかな」という罪悪感。数値の意味がよく分からない |
| ゴール | 毎日何を見ておけばいいか知りたい。次の診察できちんと伝えたい |
| 困りごと | 食欲や飲水を毎日メモするのが続かない。診察室で頭が真っ白になる |
| アプリに求めること | 迷わない少ない項目、責められない言葉、診察で見せられるまとめ |
| 避けたいこと | 赤字の警告、「危険」「悪化」などの判定表示、情報の詰め込み |

## ペルソナ B：自宅で皮下輸液を続ける多頭飼いの家族（メイン）

| 項目 | 内容 |
|---|---|
| 名前 | 田中 健一（仮）・50代と、その妻・パート |
| 猫 | 3匹。そのうち「こてつ」16歳・オスが CKD。1日おきの皮下輸液と、朝夕の投薬がある |
| 状況 | 補液は夫婦2人で行う（1人が保定、1人が針）。投薬は妻が担当 |
| 気持ち | ケアには慣れてきたが、毎日の負担が大きい。「今日はやったっけ？」がよくある |
| ゴール | 補液・投薬の抜けや重なり（二重投与）を防ぎたい。どの子の記録か混ざらないようにしたい |

| 補足 | 家族共有を望む可能性が高い。ただし家族共有は第3弾以降のため、第1弾では「1台を夫婦で使う」前提とする（仮） |

## カスタマージャーニー（ペルソナ A を中心に）

| 段階 | 1. 診断直後 | 2. 始める | 3. 毎日の記録 | 4. 診察 | 5. 長期ケア | 6. 看取り・見送り |
|---|---|---|---|---|---|---|
| 行動 | 病院で説明を受ける／ネットで調べる | アプリを入れ、猫を登録する | 食欲・飲水・体重などを記録する。補液・投薬を始める | レポートを見せる。指示が変わる | 補液・投薬の習慣化。体調の波 | 体調が落ちる／お別れ |
| 気持ち | 不安・罪悪感・混乱 | 「続けられるかな」 | 慣れと面倒くささ | 「ちゃんと伝えられた」 | 疲れ・一喜一憂 | 悲しみ・後悔 |
| 接点 | 検索・SNS（ベンガル／スコティの領域） | 初回設定 | ホーム・記録・リマインダー | レポート（PDF） | 記録・グラフ（第2弾） | 通知停止・見送りモード |
| 設計の要点 | 恐怖をあおらない（SNS 側） | 登録項目は最小限（名前だけで開始できる） | ワンタップ・前回コピー・やさしい言葉 | 期間を選んで1分以内に PDF | 「休んでもいい」と伝わる UI（未記録の日を責めない） | 通知の一括停止、記録の保存・書き出し、文言の切り替え |

## 設計上の約束（全ペルソナ共通）
1. **責めない**：未記録の日を「抜け」「失敗」と表示しない。連続記録日数のゲーム化（途切れると0になる等）はしない。
2. **判定しない**：数値・記録に色や評価をつけない（→ `01` の §4）。
3. **待てる**：通知は控えめにする。「あとで」を選んでも責めない。
4. **終わり方を用意する**：見送ったあとも記録を残せ、通知が二度と届かないようにする。
