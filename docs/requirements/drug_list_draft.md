# 薬の候補リスト 初版の案（F-26）

- 作成：ブリショー ／ 版：案 v0.3（2026-11-12。輸液剤の案と、獣医師の表記確認用の一覧を追加） ／ 状態：`draft`
- 確認の流れ（Q-25 決定）：ブリショーの案（本書） → **監修獣医師（ユーザー）が収録の可否を判断** → ロシアンがチェック → 開発担当がアプリに収録
- 関連：`04_functional_requirements.md` の F-05・F-26、`07_open_questions.md` の Q-24・Q-25

> **本書は、獣医師が確認するための社内資料です。** 飼い主さん向けの情報ではありません。
> アプリに収録するのは「製品名（と剤形・メーカー名）」だけです。本書の「区分（確認用）」の列は、獣医師が確認しやすくするための整理で、**アプリには表示しません**（効能の表示になるため。F-26）。
> 本書は、特定の薬をすすめるものではありません。投薬は、かかりつけの獣医師の指示に従ってください。

## 1. 出典の利用条件の確認（ロシアン V3-4）

**結論：動物医薬品検査所の情報は、出典を記載すれば、商用のアプリに同梱して利用できると判断しました（ブリショーの読み取り。最終的な法的判断ではありません）。** 2026-11-11 に一次情報を確認しました。

| 出典 | 確認した内容（原文の要点） | 判断 |
|---|---|---|
| 農林水産省「リンクについて・著作権」（https://www.maff.go.jp/j/use/link.html） | 「著作権は、特記されていない限り農林水産省に帰属し、権利表記の記載がない限り『公共データ利用規約（第1.0版）』（PDL1.0）に準拠した利用条件の下で、利用することができます」。出典の記載が必要（例：「出典:農林水産省ウェブサイト(当該ページのURL)」）。編集・加工した場合は「…を加工して作成」と記載し、国が作成したかのように公表・利用してはならない。適用外はロゴ・キャラクター等と、別紙で別のルールを明示したもの（別紙に挙がっているのは YouTube 動画・クッキング自給率・食事バランスガイド） | 商用利用・再配布は可能。**出典の記載が条件** |

### アプリでの扱い（案）
- 「このアプリについて」に、出典を記載する。**文案（ロシアンの推奨文。R-11 レビュー）**：
  > お薬の候補リストの一部は、「動物用医薬品等データベース」（農林水産省 動物医薬品検査所）（https://www.vm.nval.go.jp/）（2026年11月11日に利用）をもとに、運営者が加工して作成しています。国が作成・推奨したリストではありません。
  - 利用日は、リストを更新するたびに更新する。
- **製品名の表記**：製品名の多くは各メーカーの商標。ロゴ・マーク・®・™ などの装飾は付けず、**メーカー名を並べて書く**（例：「マロピタット錠１６（リケンベッツファーマ）」。表示の形は開発担当と決める）。
- **リンクを張る場合**：アプリやサイトからデータベースへリンクを張るときは、動物医薬品検査所の問い合わせ窓口に、リンク元の URL を連絡する（同所の「リンク・著作権について」のお願い）。
- 国（動物医薬品検査所）が作成・推奨したリストであるかのような表示はしない。
- 収録するのは製品名・剤形・メーカー名だけ。効能・用法・説明文・画像は転載しない。
- リストの版の記録に、確認日（2026-11-11）と上の URL を残す。

### 確認できなかったこと
- データベースの検索結果のページは、この作業環境からは取得できなかった。製品ページの URL がわかっているものだけを開いて確認した。
- メーカーのサイト（エランコ、東レ）は、この作業環境のネットワークで開けなかった。
