# 薬の候補リスト 初版の案（F-26）

- 作成：ブリショー ／ 版：案 v0.1（2026-11-10） ／ 状態：`draft`

### 確認を終えるための次の一手（いずれかを選ぶ）
1. この作業環境のネットワークの許可に `www.maff.go.jp` と `www.vm.nval.go.jp` を加えてもらい、ブリショーが利用規約のページを読んで記録する（環境の設定変更が必要。ユーザーの承認が必要）。
2. ユーザー（またはボンベイ）が、ブラウザで農林水産省の「利用規約」ページと動物医薬品検査所のデータベースの利用条件のページを確認し、要点を共有する。
3. 動物医薬品検査所に問い合わせる。

> 製品名は事実の情報で、名前の一覧を自分たちで作る分には著作権の問題は小さいと考えられます（**推測**。法的な判断ではありません）。ただし、データベースをまとめて複製する形にはしないこと、出典の記載が必要かどうかを、上の確認で決めます。

## 2. 候補の案

### 表の見方
- **確認元**：ブリショーがこの名前の存在を確かめた情報源。「検索で確認」＝ウェブ検索の結果（データベースの製品ページの題名、メーカー・販売店のページ）に名前が出ていたもの。「未確認」＝ブリショーの知識からの案で、**名前・剤形・メーカーの正しさを確かめていない**もの。
- **要確認**：収録の可否・表記について、獣医師の判断が必要なもの。
- 並び順：区分の中で五十音順。アプリでは区分を使わず、全体を五十音順・検索形式で扱う（F-26）。

### 2-3. リストに入れるか、獣医師の判断が必要なもの

| 項目 | 例 | ブリショーの案 |
|---|---|---|
| サプリメント（食品） | イパキチン（検索結果では「炭酸カルシウム＋キトサン」の粉末）、レンジアレン（区分が要確認） | **薬の候補リストには入れない**（仮）。医薬品と並べると「薬と同じ効果がある」と誤解されるおそれがある。お薬リストへの自由入力は可能。サプリの候補リストを別に作るかは、第2弾のフードのリストと一緒に検討 |
| 病院で使う注射 | エリスロポエチン製剤、マロピタット注、セレニア注射液 | **入れない**（仮）。F-05 は自宅で与える薬の記録が目的のため。病院での処置はメモに書ける |
| 皮下輸液の液 | 乳酸リンゲル液、生理食塩液 | **薬のリストには入れない**（仮）。補液の記録（F-04）に「液の名前（任意）」の欄を足すかは別の論点（下の論点 C） |
| カプロモレリン（食欲） | — | 国内の製品の有無を確認できていない。**未収録** |

## 3. 獣医師（ユーザー）に決めてほしい論点

| ID | 論点 | ブリショーの案 |
|---|---|---|
| 論点 A | 人体用医薬品は、製品名（先発品・後発品）で載せるか、一般名で載せるか | ★**一般名＋代表的な製品名** を載せ、どちらで入力しても候補に出す。後発品の個別の名前は載せない（保守できないため）。リストにない名前は自由入力 |
| 論点 B | 病院で使う注射を載せるか | ★載せない（自宅で与える薬に絞る） |
| 論点 C | 補液の液の名前を記録する欄を F-04 に足すか | ★第1弾は足さない（メモに書ける）。需要があれば第2弾で検討 |
| 論点 D | サプリメントを薬の候補リストに入れるか | ★入れない（自由入力は可） |
| 論点 E | 上の表の各行を「収録する／しない」 | 獣医師が判断する。収録範囲は「猫の CKD で処方されることがある」もの（Q-24） |

## 4. 次の手順
1. 出典の利用条件の確認（§1。**未完了**）
2. 獣医師（ユーザー）が §2 の各行と §3 の論点を判断する
3. ブリショーが「収録する」行だけで v0.2 を作り、表記（製品名・剤形・メーカー名）を一次情報で確かめる
4. ロシアンがチェックする（表示のルール F-26、人体用医薬品の条件 V3-3）
5. 開発担当がアプリに収録する。リストの版・更新日・出典を記録する
