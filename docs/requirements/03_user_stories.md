# 03 ユーザーストーリー

- 作成：ブリショー ／ 版：第3版（2026-11-09。ユーザーの「要件定義の確認シート」の回答を反映。第2版はロシアンのレビューを反映済み） ／ レビュー状態：`draft`（第3版の差分はロシアン未レビュー。第2版は `compliance_reviewed`）
- 形式：「〜として、〜したい。なぜなら〜」＋ 受け入れ条件（Given / When / Then）
- ペルソナ：A＝診断直後の飼い主さん、B＝補液中の多頭飼い家族、C＝高齢の飼い主さん（→ `02_personas.md`）

## 第1弾

### US-01 迷わず始める（A）〔F-01, F-02〕
**診断されたばかりの飼い主として、** 名前を入れるだけで記録を始めたい。**なぜなら、** 不安な中で長い登録をする余裕がないから。
- Given 初めてアプリを開いた
- When 「はじめに」の3画面を読み、同意して、猫の名前だけを入力する
- Then 3分以内（仮）にホーム画面が表示され、すぐに体調を記録できる
- And 「はじめに」には「診断や治療の判断はしません。かかりつけの獣医師の指示を優先してください」という趣旨の文が入っている（文言はロシアンのレビュー対象）

### US-02 ワンタップで体調を残す（A・C）〔F-03〕
**飼い主として、** 食欲・飲水・尿・嘔吐などをタップだけで記録したい。**なぜなら、** 毎日のことなので、手間がかかると続かないから。
- Given ホームで猫を選んでいる
- When 「体調を記録」を開き、食欲「いつもくらい」と嘔吐「1回」だけをタップして保存する
- Then 入力した2項目だけが今の時刻で保存される。未入力の項目はエラーにならない
- And 保存後に、入力値に対する評価・判定・色分けは表示されない

### US-03 前回と同じなら1タップ（A・B・C）〔F-03〕
**毎日記録する飼い主として、** 昨日と同じ内容なら一度で記録したい。**なぜなら、** 落ち着いている日に同じ入力を繰り返すのは負担だから。
- Given 前日の体調記録がある
- When 「前回と同じ」をタップする
- Then 前回の内容が今日の日付でコピーされ、確認画面で一部だけ直してから保存できる
- And コピーして直さずに保存した記録には、内部で「コピー」の印が付く（レポートでの見せ方は F-07）

### US-04 補液を記録する（B）〔F-04〕⚠️
**自宅で皮下輸液をしている飼い主として、** 量と様子をすぐ記録したい。**なぜなら、** 夫婦のどちらがやったか、やったかどうかを確かめたいから。
- Given 前回の補液で 100 mL と記録している（例。数値は表示確認のための仮の値で、推奨量ではない）
- When 補液の記録を開く
- Then 量の欄の近くに「前回 100 mL（11/8）」と、日付つきで前回の値が表示される
- And 部位を記録している場合は、「前回：背中・右（11/8）」と前回の部位が表示される。次の部位の提案はない
- And 前回の値を使う場合も、保存前に値が画面に見えている
- And アプリが量を提案・計算・評価することはない
- Given 初めて補液を記録する
- Then 量の欄は空欄で、「獣医師に指示された量を入力してください」という趣旨の案内が表示される

### US-05 通知から「やった」を記録する（B）〔F-06〕
**補液や投薬をしている飼い主として、** 通知からそのまま記録したい。**なぜなら、** ケアの直後は手がふさがっていて、アプリを開く余裕がないから。
- Given 「こてつ・朝のお薬 8:00」のリマインダーを設定している
- When 8:00 に通知が届き、「やった」をタップする
- Then アプリを開かずに、8:00台の時刻で「飲めた」の記録が保存される
- And 「あとで」を選ぶと30分後（仮）に1回だけ再通知され、それ以上は鳴らない

### US-06 どの子の記録か取り違えない（B）〔F-02, F-05〕
**多頭飼いの飼い主として、** どの猫に記録しているかを常に確認したい。**なぜなら、** 薬が猫ごとに違い、取り違えると困るから。
- Given 3匹を登録している
- When 記録画面を開く
- Then 画面の上部に、選んでいる猫の名前と写真が常に表示される
- And 猫を切り替えると、お薬リストもその猫のものに変わる

### US-06b 薬の名前を候補から選ぶ（A・B）〔F-05, F-26〕⚠️
**薬の名前を覚えにくい飼い主として、** 製品名を候補から選びたい。**なぜなら、** 正確な名前を毎回入力するのは大変で、獣医師に見せるレポートでも正しい名前で伝えたいから。
- Given お薬リストに薬を追加する
- When 名前の欄に2文字以上入力する
- Then 候補リストから一致する製品名が五十音順で表示される。「おすすめ」「人気」などの表示や、広告・購入への導線はない
- And 候補にない場合は、入力した文字のまま登録できる
- And 選んだ製品の量・回数の初期値は入らず、飼い主さんが入力する

### US-07 二重投与を防ぐ（B）〔F-05〕⚠️
**家族で投薬を分担する飼い主として、** すでに飲ませたかを確認したい。**なぜなら、** 二重に飲ませるのが心配だから。
- Given 今朝の「白い錠剤」が「飲めた」で記録済み
- When 同じ薬の記録をもう一度しようとする
- Then 「今朝 8:05 に記録済みです」と事実だけが表示され、それでも記録するか、やめるかを選べる
- And 「危険」「過剰」など、判断や警告に見える言葉は使われない

### US-08 診察で記録を見せる（A・C）〔F-07, F-12〕⚠️
**通院している飼い主として、** 前回の通院からの記録を1枚にまとめて先生に見せたい。**なぜなら、** 診察室では緊張して、うまく伝えられないから。
- Given 2週間分の記録がある
- When レポートで「前回の通院から」を選び、作成する
- Then 1分以内（目標）に PDF が作られ、共有・印刷・画面表示ができる
- And PDF には、体調の一覧・体重の推移・補液と投薬の記録・メモが入っている
- And 基準範囲・判定・「悪化」などの解釈の言葉、増減率や矢印は入っていない
- Given 3日目に嘔吐を記録しなかった（項目を入力していない）
- Then 一覧表のその欄は「0」ではなく「—（記録なし）」と表示される
- And 嘔吐の回数の合計の横に「記録のある日数 13/14日」のように記録日数が並ぶ

### US-09 休んでもいい（A・B・C）〔F-08, F-10〕
**ケアに疲れた飼い主として、** 記録しない日があっても責められたくない。**なぜなら、** 毎日完璧にはできないから。
- Given 3日間記録していない
- When アプリを開く
- Then 「記録が途切れています」などの表示は出ず、カレンダーにも「抜け」の印は付かない
- And 通知の一時停止を、理由を聞かれずに設定できる

### US-10a 通知を止めて、一覧から外す（C）〔F-10・第1弾〕
**しばらくケアができない、または猫を亡くした飼い主として、** その子の通知をすぐに止め、一覧から外したい。**なぜなら、** 補液や投薬の通知が鳴り続けるのはとてもつらいから。
- Given 「たま」の投薬リマインダーが設定されている
- When プロフィールで「一覧から外す」を選び、確認する
- Then 「たま」に関するすべての通知が、ただちに止まる
- And 理由は聞かれない
- And 記録は削除されず、設定の「一覧から外した猫」から閲覧・PDF 化・書き出し・一覧に戻すができる
- And その後、アプリから再利用の呼びかけ・アンケート・ストア評価の依頼・記念日の通知は届かない

### US-10 見送ったあと（C）〔F-25・**第2弾**〕
**愛猫を見送った飼い主として、** 通知が二度と届かないようにして、記録は思い出として残したい。**なぜなら、** 見送ったあとにケアの通知が届くのはとてもつらいから。
- Given 「たま」の投薬リマインダーが設定されている
- When プロフィールで「見送った」を選び、確認する
- Then 「たま」に関するすべての通知が、ただちに止まる
- And 記録は削除されず、「思い出」から閲覧・PDF 化・書き出しができる
- And 記録を消すかどうかをたずねる案内は出ない（消したい場合は、自分で設定から操作できる）
- And 見送りの理由・死因は聞かれない。日付の入力は任意
- And その後、アプリの再利用の呼びかけ・アンケート・ストア評価の依頼・「1年前の今日」などの通知は届かない

### US-10b 記録が止まっても、勝手に判断しない（C）〔F-10・第1弾、F-25・第2弾〕
**体調が悪い時期の飼い主として、** しばらく記録できなくても、アプリに勝手に判断されたくない。**なぜなら、** 記録が止まる理由は人それぞれだから。
- Given 30日間、記録がない
- Then アプリが自動で一覧から外したり、見送り扱いにしたり、見送りの設定を勧めたりすることはない

### US-11 大きな文字で使う（C）〔F-11〕
**目が見えにくい飼い主として、** 文字とボタンを大きくしたい。**なぜなら、** 小さな文字だと押し間違えるから。
- Given 設定で文字サイズ「特大」を選ぶ
- Then 主要画面（ホーム・記録・レポート）の文字とボタンが大きくなり、文字が切れたり重なったりしない

### US-12 データを持ち出す・消す（A・B・C）〔F-09〕
**飼い主として、** 自分の記録を書き出したり、すべて消したりしたい。**なぜなら、** 機種変更やアプリをやめるときに困らないようにしたいから。
- When 設定から CSV を書き出す
- Then 猫ごと、または全体の記録が CSV で保存できる
- When 「すべてのデータを削除」を選び、2段階で確認する
- Then 端末内のデータが削除される（第1弾は端末内保存のみ。Q-04 決定）

## 第2弾（要点のみ。受け入れ条件は第2弾の着手前に詳しく書く）

- **US-20** 療法食の名前と食べた量を記録したい（F-14、F-26）。⚠️ 候補リストは五十音順で、広告主の製品を優先表示しない。リストから広告・購入への導線はない。リストにない製品は自由入力できる。
- **US-21** 吐いたものや様子を写真で残し、先生に見せたい（F-15）。
- **US-22** 検査結果を手入力して推移を見たい（F-16）。⚠️⚠️
  - Given CRE を3回分入力した → Then 折れ線で推移が表示される。**アプリ固定の基準範囲**・IRIS の境界線・「高い／低い」の表示・警告色はない
  - Given 飼い主さんが検査用紙から基準範囲を写して入力した → Then その範囲だけが中立的な色の帯で表示される（任意）
  - Given 「獣医師から伝えられたステージ」を入力した → Then 表示・通知・広告の内容は変わらない
  - 第2弾の着手前に、あらためてロシアンのレビューを受ける（ロシアン #11）
- **US-23** 次の通院日と「聞きたいこと」を登録し、前日に知らせてほしい（F-17）。
