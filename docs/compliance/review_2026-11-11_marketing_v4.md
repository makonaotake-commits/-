## 1. 外部の獣医師（`02` §6-2）

全体の方向は適切です。主な点：
- 協賛候補との利害関係がない人を求めていること
- 推薦文として使わないこと
- 名前を出す場合も「確認者」とし、「推奨」とは書かないこと
- 学会の名前を宣伝に使わないこと
- 依頼書に、範囲・謝礼・名前を出すか・守秘・利害関係をまとめること

### 謝礼を払うかどうか
- **どちらでも法的な問題はありません**。確認の作業に対して謝礼を払うのは、通常の業務委託です。
- 予算がほぼゼロなので、払わない形で引き受けてもらえるならそれでかまいません。ただ、継続的に（四半期ごとに）頼むなら、少額でも払うほうが関係は安定します（推測）。判断はユーザーです。

### 払う場合の開示の仕方
| 状況 | 開示 |
|---|---|
| 外部の獣医師の **名前を出さない** | 開示文に「外部の獣医師にも内容を確認してもらっています」と書く場合、謝礼の有無まで書く必要は低いと考える。書いてもよい |
| 外部の獣医師の **名前を出す** | **謝礼の有無も書く**ことを推奨する（例：「確認：獣医師 ◯◯（運営者からの依頼にもとづく有償の確認）」）。名前を出すと第三者のお墨付きのように見えるため、関係を明らかにして、独立した推薦と誤解されないようにする |
| どちらの場合も | 「推奨」「おすすめ」「認定」などの言葉は使わない。外部の獣医師のコメントを広告や推薦文に使わない（`03` §5-2 の 6） |

### 利害関係の条件（依頼書に入れる）
1. **確認の対象**：次の企業との関係について、直近3年程度（期間は目安）の有無を書面で申告してもらう。
   - 協賛の候補になっているフード・療法食メーカー
   - 動物用医薬品・サプリのメーカー
   - 競合する猫の健康記録アプリ
2. **関係の内容**：顧問・講演料・原稿料・研究費・雇用・株式など。
3. 関係があっても、すぐに不可とはしない。開示したうえで依頼するかをユーザーが判断する。開示する場合は開示文に書く。
4. **申告の更新**：協賛企業が決まったとき・増えたときと、年1回に申告し直してもらう。
5. **勤務先の病院名**：外部の獣医師の名前と一緒に勤務先の病院名を出すと、その病院の広告と見られるおそれがある（獣医療法の広告制限）。病院名は出さないことを推奨する。
6. **範囲の取り決め**：確認するのは、一般的な情報の内容と表現であること。アプリやSNSを通じて個別の猫の相談に応じないこと。確認した内容の最終責任は運営者にあること。
7. **守秘**：公開前の資料を外に出さないこと。（第1弾は端末内保存なので、飼い主さんの記録データを外部の獣医師に渡すことはない。今後も渡さない）
8. **仲介サービスを使う場合（③）**：サービスの運営会社やスポンサーに、フード・医薬品メーカーとの関係がないかも確認する。

## 2. ASO の「使わない言葉」（`03` §2）

追加した「異常を知らせる」「見逃さない」「見守る」は適切です。体調変化の通知を残すことになったので、**判定・安全・技術の性能を約束する言い方**を、もう少し広く避けてください。

**追加を推奨する言葉・言い方**
| 分類 | 言葉・言い方の例 | 理由 |
|---|---|---|
| 検知・警告 | アラート、警告、危険を知らせる、変化をキャッチ、サインを見つける、病気のサイン、気づかせてくれる | アプリが異常を判定しているように見える |
| 受診の判断 | 受診の目安、受診のタイミングが分かる、病院に行くべきか分かる | 受診の判断にあたる |
| 時間・安全の保証 | 24時間見守り、もう見逃さない、安心して任せられる | 判定と安全を約束している。通知が届かないこともある |
| 技術の性能 | AI、自動で分析、予測、スコア、健康度、ステージが分かる | 判定・評価の機能があるように見える（要件にない機能） |
| 効果 | 数値が良くなる、進行を遅らせる、健康を守る、腎臓を守る | 効果をうたっている（初期リスク A-6） |
| 連携 | 動物病院と連携、先生に自動で届く | 第1弾に連携はない（マーケレビュー #9） |

**通知機能の書き方（案）**：「あなたが決めた条件にあてはまる記録があったときに、そのことをお知らせします。判定や診断はしません。」のように、**本人が設定した条件**と**事実だけ**を伝えることを、ストア説明文でも明記する。通知の具体的な文言は、ブリショーの要件追加と一緒にレビューします。

- これらの言葉は、禁止語リスト（NFR-TONE-06）にまとめて、アプリ・ストア・Instagram・LP で共通に使ってください。
