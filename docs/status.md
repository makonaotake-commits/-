## ロシアンが挙げた初期リスク（いずれも重大度：高）
1. SaMD 該当性：検査値から判定・重症度・治療方針を示すと医療機器プログラムになり得る
2. 広告表現：効果断定・体験談・ビフォーアフター・恐怖訴求
3. 要配慮個人情報：同意取得・第三者提供（家族共有・医療機関連携・外部SDK）

## 調査環境の制約（アビシニアン報告）
- Web 検索は可。Instagram / X / TikTok / YouTube はログインが必要で投稿の実数はほぼ取れない（記事・検索結果で補う）
