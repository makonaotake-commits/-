## 初期リスク（猫向け前提・ボンベイが仮整理。ロシアンの確認待ち）
1. **獣医師法・動物用医療機器プログラム**：検査値や体調から IRIS ステージを判定する、補液量・投薬量・治療方針を提案する等は「診療」や医療機器に当たり得る（重大度：高の見込み）
2. **広告・表示（景品表示法・薬機法〔動物用〕・ペットフード表示）**：「腎臓が回復」「長生きできる」等の断定、体験談・ビフォーアフター、サプリやフードの医薬品的な効能表示、療法食の扱い（重大度：高の見込み）
3. **個人情報と表現の倫理**：飼い主の氏名・連絡先・動物病院名などの扱い、病院連携・保険会社・外部 SDK への提供時の同意。看取り・ペットロス・罪悪感への配慮（重大度：中〜高の見込み）

## 調査環境の制約（アビシニアン報告）
- Web 検索は可。Instagram / X / TikTok / YouTube はログインが必要で投稿の実数はほぼ取れない（記事・検索結果で補う）
