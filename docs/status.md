## 初期リスク（ロシアン整理済み・33項目）
詳細は `docs/compliance/initial_risks_2026-11-09.md`。重大度「高」の要点：検査値グラフに警告色・IRIS境界線を出さない／補液・投薬量の推奨値を出さない／記録画面・レポート・通知に広告を出さない／療法食広告に「獣医師の指導のもとで」必須、サプリ・動物用医薬品はMVPで受けない／健康データを広告ターゲティングに使わない／個別相談に答えない方針／Instagram承認後の修正は再承認・PR表示／お別れ設定で通知と広告を停止

## 調査環境の制約（アビシニアン報告）
- Web 検索は可。Instagram / X / TikTok / YouTube はログインが必要で投稿の実数はほぼ取れない（記事・検索結果で補う）
