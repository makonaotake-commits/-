## 1. 線のタッチ（3案）

| 案 | 内容 | 長所 | 気をつける点 |
|---|---|---|---|
| t1 ★ 色ずれの線 | 線画に、少しずらした淡い色の面を重ねる（版画・リソグラフ風） | 手しごとの雰囲気でおしゃれ。面の色で毛色も表せる | 面の色は 2 色まで（はちみつの淡色・セージの淡色） |
| t2 まる形 | 円と弧だけで組み立てる。鼻にだけ色 | 小さく表示してもくずれにくい。UI 部品となじむ | 少し記号的で、手ざわりは弱い |
| t3 ひと筆書き | 一本の線で描く。色は点 1 つ | いちばん軽やかで大人っぽい | 小さいと線が細く見える。アイコンには不向き |

共通：線は焦げ茶、端は丸い。苦しむ・泣く・ぐったりした猫、目を閉じて横たわる猫は描かない。ユリ・ネギ類のほか、**桜の枝葉など猫に有害とされる植物も描かない**（植物は「若葉」「落ち葉」など特定しない形にする）。

## 2. 記録を続けたくなる工夫（複数選択）

| 工夫 | 内容 | ★ |
|---|---|---|
| 記録したときの小さなしぐさ | 保存すると案内役がしっぽを 1 回ゆらし、目を細める。文言は「記録しました」だけ。音なし。「視差効果を減らす」設定ではアニメーションなし | ★ |
| 季節の差し替え | ホームの小さな絵が季節で変わる（春：若葉、夏：風鈴、秋：落ち葉、冬：ちらつく雪）。行事の絵は入れない | ★ |
| 時間帯の日だまり | 朝・昼・夜で日だまりの位置や月が変わる | |
| しぐさのバリエーション | ホームの猫のしぐさが日によって順番に変わる（記録の量や体調とは無関係） | ★ |
| 案内役の毛色を選べる | 最初の設定で、しろ・キジトラ・くろ・三毛などから選ぶ。あとで変更・元に戻すことも可 | |
| 記録した日に小さな葉っぱ | 記録のある日だけカレンダーに葉っぱ。数は数えず、記録のない日に印や色はつけない | 要確認 |

### やらないこと（せかさない・責めない・判定しない）
- ほめ言葉・はげまし（「えらい」「がんばったね」など）、評価、連続日数、達成率、目標、紙吹雪などの大きな演出。
- **記録の内容によって反応を変えること**（嘔吐を記録しても、食欲を記録しても同じ反応）。内容で変えると、アプリが良し悪しを判定しているように見えるため。
- 記録が少ない・ない日を目立たせる表示（F-28 のロシアン指摘と同じ考え方）。
- お休み中の猫・一覧から外した猫・見送りのあとには、季節やしぐさの演出、記録時の反応を出さない（静かな表示にする）。

## 3. 配色 c3（ひだまり寄り）の画面用調整

前回の c3 から、補助文字を `#75644F` → `#6F5E4A` に変え、入力欄などの縁用に `borderStrong` を追加。コントラスト比は WCAG 2.x の式で計算。

| トークン（案） | 明るい表示 | 暗い表示 | 用途 |
|---|---|---|---|
| `background` | `#FBF5EA` | `#1F1A14` | 画面の背景 |
| `surface` | `#FFFDF8` | `#2A231B` | カード |
| `text` | `#4D3F33` | `#F3E8D8` | 本文・線画の線・グラフの線 |
| `textSub` | `#6F5E4A` | `#C2B19A` | 補助の文字 |
| `border` | `#E6D7C0` | `#43382B` | 区切り線（飾り） |
| `borderStrong` | `#9A8468` | `#8E7B62` | 入力欄・選択肢の縁（3 以上が必要なもの） |
| `primary` | `#87602F` | `#E2B87F` | 主役のボタン（はちみつ色） |
| `onPrimary` | `#FFFFFF` | `#1F1A14` | 主役のボタンの文字 |
| `primaryTint` | `#F3E3C8` | `#3E3222` | 選択中の背景・線画の面 |
| `accent` | `#8FB5A8` | `#9CC3B5` | セージ（飾りだけ。文字には使わない） |
| `accentTint` | `#E2EDE8` | `#263530` | 線画の面・タグの背景 |

| 組み合わせ | 明るい | 暗い | 基準 |
|---|---|---|---|
| text／background | 9.33 | 14.26 | 4.5 |
| text／surface | 9.96 | 12.80 | 4.5 |
| textSub／background | 5.73 | 8.26 | 4.5 |
| textSub／surface | 6.12 | 7.42 | 4.5 |
| text／primaryTint | 8.02 | 10.30 | 4.5 |
| text／accentTint | 8.44 | 10.61 | 4.5 |
| onPrimary／primary | 5.61 | 9.37 | 4.5 |
| primary／surface（ボタンの形） | 5.52 | 8.41 | 3 |
| borderStrong／surface | 3.52 | 3.81 | 3 |
| borderStrong／background | 3.29 | 4.24 | 3 |
| accent／surface | 2.21 | 8.04 | 飾りのみ（明るい表示では意味を持たせない） |

- はちみつ色は「黄色の注意色」に見えないよう、茶寄りの `#87602F` を使う。記録のお知らせ（F-27）の目印には `primary` も使わず、`text` 色の中立的な形（例：小さな葉っぱ・しおり）にする予定（スタイルガイドで確定し、ロシアンが確認）。

## 4. 「ねこと、ゆっくり」の確認結果（2026-11-12）

| 確認先 | 結果 |
|---|---|
| 日本の App Store | **確認できず**。作業環境から apps.apple.com・itunes.apple.com（検索 API）に接続できない（プロキシで拒否） |
| Google Play（日本） | **確認できず**。play.google.com に接続できない |
| J-PlatPat（商標） | **確認できず**。j-platpat.inpit.go.jp に接続できない |
| Instagram のアカウント名 | **確認できず**。instagram.com に接続できない |
| Web 検索（参考） | 同名のアプリは見つからず（11/11 の検索と同じ）。ただし **YouTube のハンドル `@nekotoyukkuri` は「ゆっくりと猫の生活」というチャンネルが使用中**、X に `@yukkuritoneko` あり。どちらも「ゆっくり実況」系の猫動画 |

気づいた点：
- 「ゆっくり」は「ゆっくり実況・解説」（動画の一ジャンル）の言葉としても広く使われていて、検索でそちらが混ざる可能性がある【推測】。ストアの名前とサブタイトル（「腎臓病の猫のケア記録」）で区別がつくようにする。
- SNS のアカウント名は `nekotoyukkuri` が YouTube で使われているため、別の形（例：`nekoto_yukkuri_app`、`nekotoyukkuri.app`）を候補にする【空きは未確認】。
- 確認の方法：ユーザーがスマホや PC で、App Store・Google Play で「ねことゆっくり」を検索、J-PlatPat の「商標検索」で「ねことゆっくり」「ネコトユックリ」を称呼検索（区分は第9類〔アプリ〕・第42類〔ソフトウェアの提供〕・第44類〔動物の健康管理の情報提供〕が目安【要確認・弁理士に相談推奨】）、Instagram でアカウント名を入力。作業環境で確認するには、これらのホストへの接続許可が必要。
