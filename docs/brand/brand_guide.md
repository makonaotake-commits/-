## 2. ロゴとアプリアイコン（確定版・2026-11-22）

決定の流れ：ロゴ確認シート（`answers/brand_logo`）で「水平線つき」→ アイコンは方向の再検討を経て「B 縁から見上げる」→ ひげ「2本・短め」→「ネズミっぽい」を直した **f2** で確定（`docs/kickoff_answers.md`）。ロゴも f2 の顔にそろえる。

### 2-1. 形（アイコンとロゴで共通）
- 水平線（縁）から、猫が顔と前足を出して見上げている。
- 頭：上が平ら気味で、ほおが張った猫の形（半円にしない。半円だとネズミに見える）。輪郭にすきまを1か所。
- 耳：頭の角から立つ三角。内側に短い線を1本ずつ。
- 目：縦長の楕円。鼻：小さな逆三角。口：「人」の字（「ω」にしない）。
- ひげ：左右2本ずつ、短め、少し下向き。
- ベタ：しっぽ1か所（太い線）。
- **やってはいけないこと**：十字・カルテ・聴診器・ハートの心電図など医療を思わせる記号を足す／腎臓の図を入れる／傾ける・影・グラデーション／ロゴやアイコンに文字（禁止語を含む）を入れる／ベタを2か所以上にする／目を閉じた顔にする。
- 生成：`assets/tools/generate_svg.js`（`peekCat(c,"f2")`）→ PNG は `assets/tools/render_final_png.js`。手で SVG を直さない。

- 余白：マークの頭の幅の半分を、まわりに空ける。最小サイズ：マーク 24px（アプリ内）・12mm（印刷）。

## 3. 配色（c3 ひだまり寄り・画面用に調整）

トークン名と値は `ui_style_guide.md` §2 にあります（明るい表示・暗い表示とも）。

| 色 | 役割 | 決まり |
|---|---|---|
| クリーム `background` | 背景 | 余白を多くとる |
| 焦げ茶 `text` | 文字・線画の線・グラフの線 | 真っ黒（#000）は使わない |
| はちみつ `primary` | 主役のボタン・ロゴの日だまり・猫の鼻 | 1画面に主役のボタンは1つ。**注意・警告の意味を持たせない** |
| 淡いはちみつ `primaryTint` | 選択中の背景・アイコンの地 | |
| セージ `accent` / `accentTint` | 線画の面・タグ・カレンダーの葉っぱ | 飾りだけ。セージを文字の色に使わない。「良い・正常」の意味を持たせない |

- **信号の色（赤・黄・緑）で、記録や数値を塗り分けない。**
- 強調は1か所だけ。ネオンのような強い色は使わない。
- 見送り・ペットロスに関わる画面や資材では、`primary` を使わず、`background`・`text`・`border`・`accentTint` だけにする。
- Instagram は、引き続きミルクティー案の色で運用してかまわない（スコティの決定）。ただし、アプリ画面のスクリーンショットを載せるときは、この配色の画面をそのまま使う。

| 本文・数字・単位 | BIZ UDPGothic | Regular 400／Bold 700 |

## 5. ラインアートとマスコット（まる形・清書タッチ a）

決定：線画シート（11/15 09:50）で「まる形」、清書シート（`answers/brand_art_v3`、11/15 10:14）で **タッチ a「細い線＋しっぽのベタ」** と **案内役「縁からのぞく」**。ユーザーの参考画像2枚（他の作家の作品）からは、雰囲気と線の考え方だけを取り入れ、キャラクターや構図は写していない。

### 5-1. 描き方
| 項目 | ルール |
|---|---|
| 形 | 円・楕円・弧だけで組み立てる。頭は正円、体は半円か楕円、耳は小さな弧1本ずつ、しっぽは弧 |
| 線 | `text` 色の単線。**太さ 1.8**（120×80 の viewBox 基準）。端と角は丸い。真っ黒（#000）は使わない |
| すきま | 頭と体の輪郭に、すきま（線の切れ目）を1〜2か所入れて、閉じきらない。地面の線にも切れ目を1か所 |
| ベタ塗り | **1枚の絵に1か所だけ。** 猫はしっぽ（線の3倍の太さで描く）。季節の小物は、その小物の一部（若葉の1枚・短冊・どんぐりの帽子・雪の1粒） |
| 面 | 頭は `surface` で塗り、後ろの線を隠す。ほかは塗らない |
| 顔 | 目は点2つ、鼻は小さな点。口は描かない。表情はおだやか |
| 構図 | 水平線（床・テーブル・カードの縁）を1本引き、猫はその上にいるか、縁からのぞく。余白を広くとり、絵は小さく置く |
| しぐさ | すわる・のぞく・のびる・香箱・窓の外を見る（うしろ姿）。動きのあるしぐさも、目は開けて描く |
| 毛色 | §6 の「案内役の毛色を選べる」で使う。キジトラは頭に短い線3本、三毛・ぶちは頭に小さな面を1つ（このときもベタはしっぽ1か所のまま、面は `primaryTint`）。くろは頭を `text` で塗り、目を `surface` にする（例外としてベタが2か所になるのを許す） |
| 色 | 線とベタ `text`、頭 `surface`、時間帯の太陽・月だけ `primary`。暗い表示は `dark/` のファイル |

### 5-2. 描かないもの
- 苦しむ・泣く・ぐったりした猫。**横たわって目を閉じた姿**（眠る姿を描くときも、すわった姿勢か、丸まって目を開けた姿にする）。
- 天使の輪・羽・虹の橋など、亡くなったことを思わせる記号。
- 針を刺す瞬間・血・注射器を目立たせた絵。補液や投薬の道具は、小さな記号として描く。
- 猫に有害とされる植物：ユリ、桜の枝葉など。植物は「若葉」「色づいた葉」など、種類を特定しない形にする。ネギ類・チョコなどの食べ物も描かない。
- 散る・枯れるものを、看取りを連想させる形で描かない（秋は「落ち葉」ではなく「色づいた葉」「どんぐり」。ロシアンの指摘）。
- 参考画像のキャラクター・構図・小物をそのまま写すこと。

### 5-3. 案内役（縁からのぞく猫）
- 原画：`assets/svg/light/guide/guide_peek.svg`（暗い表示は `dark/guide/`）。水平線から、頭と前足だけをのぞかせる。
- 役割：ホームの見出しの横や、記録の完了表示のそばに1つだけ置く。見出しやカードの縁の線に重ねて置くと、「縁からのぞく」形になる。案内役は**しゃべらない**（吹き出しで励ましたり、提案したりしない）。
- 記録したときの反応：首を少しかしげ（`#head` を下端中央を軸に −9°）、しっぽを1回ゆらす（`#tail` を付け根を軸に −14°→+6°）。合計 1.6 秒以内・1回だけ。何を記録しても同じ。「演出を控えめにする」または OS の動きを減らす設定がオンなら動かさない（§6-1）。
- 毛色は、最初の設定で飼い主さんが選べる（§6）。初期値は「しろ」。

### 5-4. アセットのファイル名とサイズ（マンチカン向け）

|---|---|---|---|---|
| `guide/` | `guide_peek.svg` | 0 12 64 32 | 幅 56〜72（高さは比率で 28〜36） | 見出しの横・記録の完了表示 |
| `poses/` | `pose_sit.svg`・`pose_peek.svg`・`pose_stretch.svg`・`pose_loaf.svg`・`pose_window.svg` | 0 10 120 80 | 幅 120〜180（ホーム上部の絵） | しぐさのバリエーション（日付で順番に） |

| `daypart/` | `daypart_morning.svg`・`daypart_noon.svg`・`daypart_night.svg` | 0 0 76 48 | 幅 48〜76 | ホームの絵の背景の小物 |
| `logo/` | `logo_mark.svg`・`logo_mark_horizon.svg` | 0 0 120 100 | 幅 24 以上 | スプラッシュ・設定の「このアプリについて」 |

| 毛色 | 入れ方（ベタはしっぽ1か所のまま） | 明るい表示 | 暗い表示 |
|---|---|---|---|
| しろ | 顔は `surface` | `#FFFDF8` | `#2A231B` |
| キジトラ | 淡い面＋おでこの縞3本・ほおの線（線で描く。「縁からのぞく」形ではほおの線を省く） | `#E8DCC8` | `#3B3228` |
| くろ | 顔を塗る（例外）。明るい表示は目・鼻を地の色に、暗い表示は顔を地より暗くして目・鼻は線の色のまま | `#4D3F33` | `#0E0C09` |

## 6. 記録を続けたくなる工夫（6つすべて採用）

### 6-1. 共通のルール（せかさない・責めない・判定しない）
- **ほめない・評価しない・煽らない**：「えらい」「がんばったね」などの言葉、点数、連続日数、達成率、目標、ランク、紙吹雪などの大きな演出は使わない。
- **記録の内容で反応を変えない**：嘔吐を記録しても、食欲を記録しても、同じ反応にする。
- **数えない・ためない**：何かが育つ、集まる、コレクションになる、という形にしない。
- **お休み中の猫・一覧から外した猫・見送りのあと**は、季節・時間帯・しぐさの演出と、記録したときの反応を止め、静かな表示にする。外した猫の写真やしぐさを、ほかの猫の画面の演出に使わない。
- **設定に「演出を控えめにする」スイッチを置く**（ロシアンの再検討、`docs/compliance/review_2026-11-12_brand_art_v2.md`）。第1弾のアプリは、猫を見送ったことを知らないため。
  - オンにすると、季節の差し替え・時間帯の絵・しぐさの変化・記録したときの反応を止め、静かな絵1枚と「記録しました」の文字だけにする。
  - 理由は聞かない。自動ではオンにしない。
  - 「一覧から外す」と「お休み」の画面に、このスイッチがあることを1行で添える。
- 端末の「視差効果を減らす」（iOS）・「アニメーションを削除」（Android）の設定がオンのときも、「演出を控えめにする」と同じ表示にする。音は出さない。

### 6-2. 6つの工夫
| 工夫 | 決まり |
|---|---|
| 記録したときの小さなしぐさ | 保存したときに、案内役がしっぽを1回ゆらし、目を細める（1.6秒以内・1回だけ）。文言は「記録しました」だけ |
| 季節の差し替え | ホームの小さな絵を季節で変える。春：若葉／夏：風鈴／秋：色づいた葉・どんぐり／冬：ちらつく雪。月で切りかえる（3〜5月・6〜8月・9〜11月・12〜2月）。行事の絵（クリスマス・お正月など）は入れない |
| 時間帯の日だまり | 端末の時刻で、朝（5〜10時）・昼（10〜17時）・夜（17〜5時）に絵を変える。夜は暗い表示に合う、落ち着いた絵にする |
| しぐさのバリエーション | ホームの猫のしぐさ（すわる・香箱・窓の外を見る、など）を、日付で順番に変える。記録の量や体調とは関係させない |
| 案内役の毛色を選べる | 最初の設定と設定画面で選ぶ。いつでも変えられ、初期値に戻せる。「うちの子」の写真から自動で作る機能にはしない |
