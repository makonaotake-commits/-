## 2. ロゴ（l1：丸まってくつろぐ猫）

- 原画：`assets/svg/logo_mark.svg`（ラフ。まる形のタッチで描き直したもの）
- 構成：楕円の体＋丸い頭＋三角の耳＋しっぽの弧＋小さな日だまり（はちみつ色の丸）。
- **目は開けて描く。** 横たわって目を閉じた姿に見えないようにする（ペットロスへの配慮。ロシアンの指摘）。
- ワードマーク：「ねこと、ゆっくり」を Zen Maru Gothic Bold で組む。マークの右か下に置く。
- 余白：マークの頭の直径ぶんを、まわりに空ける。
- 最小サイズ：マークは 24px（アプリ内）・12mm（印刷）。これより小さいときは日だまりの丸を省く。
- 色：線は `text`、体は `accentTint`、頭と耳は `surface`、日だまりと鼻は `primary`。暗い表示では、同じ名前のトークンの暗い値を使う。単色のときは `text` 1色で描く。
- **やってはいけないこと**：十字・カルテ・聴診器・ハートの心電図など、医療を思わせる記号を足す／腎臓の図を入れる／傾ける・影をつける・グラデーションにする／ロゴの中に禁止語を入れる。
- アプリアイコン：`primaryTint` の角丸の正方形に、日だまりなしのマークを置く（清書はストア画像と一緒に作る）。

## 3. 配色（c3 ひだまり寄り・画面用に調整）

トークン名と値は `ui_style_guide.md` §2 にあります（明るい表示・暗い表示とも）。

| 色 | 役割 | 決まり |
|---|---|---|
| クリーム `background` | 背景 | 余白を多くとる |
| 焦げ茶 `text` | 文字・線画の線・グラフの線 | 真っ黒（#000）は使わない |
| はちみつ `primary` | 主役のボタン・ロゴの日だまり・猫の鼻 | 1画面に主役のボタンは1つ。**注意・警告の意味を持たせない** |
| 淡いはちみつ `primaryTint` | 選択中の背景・アイコンの地 | |
| セージ `accent` / `accentTint` | 線画の面・タグ・カレンダーの葉っぱ | 飾りだけ。セージを文字の色に使わない。「良い・正常」の意味を持たせない |

- **信号の色（赤・黄・緑）で、記録や数値を塗り分けない。**
- 強調は1か所だけ。ネオンのような強い色は使わない。
- 見送り・ペットロスに関わる画面や資材では、`primary` を使わず、`background`・`text`・`border`・`accentTint` だけにする。
- Instagram は、引き続きミルクティー案の色で運用してかまわない（スコティの決定）。ただし、アプリ画面のスクリーンショットを載せるときは、この配色の画面をそのまま使う。

## 5. ラインアートとマスコット（t2 まる形）

### 5-1. 描き方
| 項目 | ルール |
|---|---|
| 形 | 円・楕円・弧・角の丸い三角だけで組み立てる。頭は正円、体は半円か楕円、しっぽは弧 |
| 線 | `text` 色、太さ一定（100 単位の viewBox で 2、アイコンの 24px で 1.5 くらい）、端と角は丸い |
| 面 | `surface`・`accentTint`・`primaryTint` のベタ塗り。1匹に使う面の色は2色まで。グラデーション・影なし |
| 差し色 | 鼻の小さな丸だけ `primary`（はちみつ色） |
| 顔 | 目は小さな点。口は描かないか、小さな弧1本。表情はおだやか |
| 毛色 | しろ・キジトラ（頭に短い線3本）・くろ（面を `text`、目を `surface`）・三毛（頭に小さな面を2つ）・茶・グレーなど。ほっそりしたシニア猫も、悲しそうに見えないよう同じ顔で描く |

### 5-2. 描かないもの
- 苦しむ・泣く・ぐったりした猫。**横たわって目を閉じた姿**（眠る姿を描くときも、すわった姿勢か、丸まって目を開けた姿にする）。
- 天使の輪・羽・虹の橋など、亡くなったことを思わせる記号。
- 針を刺す瞬間・血・注射器を目立たせた絵。補液や投薬の道具は、小さな記号として描く。
- 猫に有害とされる植物：ユリ、桜の枝葉など。植物は「若葉」「色づいた葉」など、種類を特定しない形にする。ネギ類・チョコなどの食べ物も描かない。
- 散る・枯れるものを、看取りを連想させる形で描かない（秋は「落ち葉」ではなく「色づいた葉」「どんぐり」。ロシアンの指摘）。

### 5-3. 案内役（小さな猫アイコン）
- 原画：`assets/svg/guide_cat.svg`（ラフ）。顔と耳と、しっぽの弧だけの小さなアイコン。
- 役割：ホームの見出しの横や、記録の完了表示のそばに1つだけ置く。案内役は**しゃべらない**（吹き出しで励ましたり、提案したりしない）。
- 毛色は、最初の設定で飼い主さんが選べる（§6）。初期値は「しろ」。

## 6. 記録を続けたくなる工夫（6つすべて採用）

### 6-1. 共通のルール（せかさない・責めない・判定しない）
- **ほめない・評価しない・煽らない**：「えらい」「がんばったね」などの言葉、点数、連続日数、達成率、目標、ランク、紙吹雪などの大きな演出は使わない。
- **記録の内容で反応を変えない**：嘔吐を記録しても、食欲を記録しても、同じ反応にする。
- **数えない・ためない**：何かが育つ、集まる、コレクションになる、という形にしない。
- **お休み中の猫・一覧から外した猫・見送りのあと**は、季節・時間帯・しぐさの演出と、記録したときの反応を止め、静かな表示にする。外した猫の写真やしぐさを、ほかの猫の画面の演出に使わない。
- 端末の「視差効果を減らす」（iOS）・「アニメーションを削除」（Android）の設定がオンなら、動きは出さない。音は出さない。

### 6-2. 6つの工夫
| 工夫 | 決まり |
|---|---|
| 記録したときの小さなしぐさ | 保存したときに、案内役がしっぽを1回ゆらし、目を細める（1.6秒以内・1回だけ）。文言は「記録しました」だけ |
| 季節の差し替え | ホームの小さな絵を季節で変える。春：若葉／夏：風鈴／秋：色づいた葉・どんぐり／冬：ちらつく雪。月で切りかえる（3〜5月・6〜8月・9〜11月・12〜2月）。行事の絵（クリスマス・お正月など）は入れない |
| 時間帯の日だまり | 端末の時刻で、朝（5〜10時）・昼（10〜17時）・夜（17〜5時）に絵を変える。夜は暗い表示に合う、落ち着いた絵にする |
| しぐさのバリエーション | ホームの猫のしぐさ（すわる・香箱・窓の外を見る、など）を、日付で順番に変える。記録の量や体調とは関係させない |
| 案内役の毛色を選べる | 最初の設定と設定画面で選ぶ。いつでも変えられ、初期値に戻せる。「うちの子」の写真から自動で作る機能にはしない |
| 記録した日に小さな葉っぱ | F-08 の「記録した日の点」の形を、葉っぱにしたもの。ロシアンの条件：①数えない・ためない ②形・大きさ・色は1種類だけ（件数や内容で変えない） ③カレンダーの中だけに出す（ホームに並べない） ④記録のない日は何も出さない ⑤お知らせの目印と別の形にする。原画：`assets/svg/mark_calendar_leaf.svg` |

## 7. 記録のお知らせ（F-27）の目印
- 形：**しおり**（`assets/svg/mark_notice.svg`）。カレンダーの葉っぱとは別の形にする。
- 色：`text` 色の線だけ。**赤・黄・感嘆符・ベルの強調・点滅・バッジの数字は使わない。** 動かさない。
- 文言は F-27 の推奨文案（`docs/requirements/`）に従う。目印の横に評価の言葉を添えない。

## 8. 言葉づかい（ロゴ・ストア画像・資材にも当てはまる）
- 禁止語（NFR-TONE-06・06b）は、画面だけでなく、**ロゴ、ストア画像、LP、チラシなどの文字にも当てはまる**。例：治る・回復・悪化・危険・手遅れ・アラート・警告・病気のサイン・受診の目安・見守る・見逃さない・AI・自動で分析・予測・スコア・健康度・腎臓を守る・進行を遅らせる・動物病院と連携 など（全文は `docs/requirements/05_non_functional_requirements.md`）。
- 「長く」「長生き」「少しでも長く一緒に」は使わない（効果をほのめかすため）。
- ストア画像・LP・資材にアプリの画面を載せるときは、**薬の名前を「お薬A」のような架空の名前にする。** 実在の製品名は出さない（ロシアン P-1）。猫の名前・数値も、架空のサンプルであることがわかるものにする。
- 「獣医師監修」の表示は、監修が運営者本人であることの開示（`docs/marketing/02_positioning.md` §6）とセットで使う。

## 10. 「ねこと、ゆっくり」の確認状況（2026-11-15 に再確認）

| 確認先 | 結果 |
|---|---|
| Google Play（日本） | 「ねことゆっくり」「ねこと、ゆっくり」「ねこと ゆっくり」で検索。**同じ名前・ほぼ同じ名前のアプリはなし**。結果の上位は、猫のゲーム（ねこあつめ など）と「ゆっくり」系（ゆっくり育てていってね！、ゆっくり棒読みトーク など） |
| App Store（日本） | **確認できず**（作業環境から apps.apple.com・itunes.apple.com に接続できない） |
| J-PlatPat（商標） | **確認できず**（接続はできたが、11/15 は「メンテナンス作業によりサービスを停止」と表示された） |
| Instagram のアカウント名 | **確認できず**（instagram.com に接続できない）。参考：YouTube の `@nekotoyukkuri` は別の猫動画チャンネルが使用中 |

- Google Play の結果から、「ゆっくり」で検索すると「ゆっくり実況・解説」系のアプリが多く混ざることがわかった。名前だけで探してもらうのは難しいため、タイトル後半とサブタイトルの「猫の腎臓病ケア記録」「補液・お薬・体調」で見つけてもらう前提にする。
- 商標は、公開前にユーザーが J-PlatPat の称呼検索で確かめるか、弁理士に相談することを推奨（ロシアンも同じ意見）。
