# 体験の見本用の絵（猫の部屋・カード・絵日記・話しかける猫・なでる）

- 作成：ペルシャ／2026-11-23 ／ 依頼：ボンベイ（ユーザーの選択「体験の形式」、`docs/kickoff_answers.md`）
- 状態：`draft`（見本用。ユーザーが体験を選んだあとに清書・追加する）
- 生成：`docs/brand/assets/tools/generate_svg.js`（手で SVG を直さない）
- 全体の見本：`docs/brand/assets/png/experience/experience_assets.png`
- どの絵も f2 の顔・線画ルール（細い線・すきまのある輪郭・ベタはしっぽ1か所）。猫が入るものは毛色6種（接尾辞なし＝しろ、`_tabby`・`_black`・`_calico`・`_brown`・`_gray`）× 明暗（`light/`・`dark/`）
- 気持ちは「落ち着く・安心する」。動きや色は控えめに。答えの絵のルール（表情・色で良し悪しを付けない、「静か」を具合が悪そうにしない）を守る。

## ① 猫の部屋（`svg/{light|dark}/room/`）
部屋の部品は、すべて同じ viewBox `0 0 360 240` なので、重ねるだけで組み上がる。床は y=200。

| 重ねる順 | ファイル | 内容 |
|---|---|---|
| 1 | `window_morning`・`window_noon`・`window_evening`・`window_night` | 窓（左上、アーチ形。十字の桟は入れない）。時間帯で空の色と太陽・月が変わる |
| 2 | `weather_cloudy`・`weather_rain`・`weather_snow` | 窓の中の天気（晴れは重ねない） |
| 3 | `floor`・`bed`・`toilet_back`・`shelf`・`wall_picture` | 床、寝床、トイレの奥側、棚（本と小さな鉢）、壁の絵（景色。猫の写真の額は遺影を思わせるので描かない） |
| 4 | 猫（下の表） | 場所ごとに置く |
| 5 | `bowl_food`・`bowl_water`・`toilet_front` | 手前の器とトイレの手前側（猫の前に重ねる）。部屋の器は、スマホ幅でも分かるよう 1.3 倍（2026-11-23） |

猫のしぐさ（`room/cat_walk`・`cat_bed`、ほかに `poses/pose_sit`・`pose_window`。食べる・飲む姿は描かない＝ロシアン E-1・E-3）は 120×80（地面 y=80）。しぐさの「地面の中央（60,80）」を、次の点に合わせて置く（倍率 1.0）。

| 場所 | 点 (x, y) | しぐさ | 手前に重ねるもの |
|---|---|---|---|
| 寝床 | (72, 196) | `cat_bed`（丸まって目を開けてくつろぐ） | — |
| 窓辺 | (72, 192) | `pose_window`（寝床の上から、うしろ姿で窓の外を見る。窓が寝床の真上にあるので、寝床と重なるのは意図どおり） | — |
| ごはん | (153, 196) | `pose_sit`（器の後ろにすわる。食べる姿にしない） | `bowl_food` |
| お水 | (199, 196) | `pose_sit`（器の後ろにすわる。飲む姿にしない） | `bowl_water` |
| トイレ | (292, 194) | `pose_sit` | `toilet_front` |
| 歩く | (240, 200) | `cat_walk`→`cat_walk2`→`cat_walk3`→`cat_walk2`…（脚だけ違う3コマ。0.25秒ずつが目安。F-30 オンなら `cat_walk` 1枚で移動させずに置く） | — |

- 季節は、窓辺や床に `seasons/season_*` を小さく置く（窓の外の木などは描かない）。
- 「寝ている」場面は、横たわって目を閉じた姿にしない（brand_guide §5-2）。寝床で丸まって、目を開けた姿で表す。

## ② カード（`svg/{light|dark}/cards/`、160×120）
`card_food`（ごはんの器）・`card_water`（お水の器としずく）・`card_toilet`（トイレとスコップ）・`card_energy`（すわる猫。毛色ごと）。答えの選択肢の絵ではなく、問いの絵柄。

## ③ 絵日記（`svg/{light|dark}/diary/`、200×140）
1コマの完成形：`diary_meal`（ごはんの器の横にすわる）・`diary_drink`（お水の器の横にすわる）・`diary_rest`（寝床でくつろぐ）・`diary_window`（窓辺）。枠つき。毛色ごと。食べる・飲む動作は描かない（ロシアン E-1）。
記録した項目は、コマの隅に小さなアイコンで示す：`diary/item_food`・`item_water`・`item_toilet`・`item_energy`・`item_fluid`（補液）・`item_med`（お薬）。24×24、線だけ。

## 絵日記の地（3案）
`diary/paper_lines`（罫線のノート）・`paper_dots`（方眼の点）・`paper_tape`（マスキングテープで留めた紙）。200×140 の枠と同じ大きさで、場面の絵の下に敷く。記録の値では変えない。

## 答えの絵（`svg/answers/`、24×24、線は currentColor）
- 食べた量：`answer_food_0`（平らな線だけ）・`_1`（山1つ）・`_2`（山2つ）・`_3`（山3つ）
- お水：`answer_water_1`（しずく1つ）・`_2`（2つ）・`_3`（3つ）
- どの段階も、同じ形・同じ大きさの部品の「数」で表す。大きさ・色・表情で良し悪しを示さない。器の残りの絵にはしない（ロシアン T-3）。明・暗は currentColor で切りかえる。
- 見本：`docs/brand/assets/png/experience/answers.png`

## ④ 話しかける猫（`svg/{light|dark}/talk/`）
`talk_face`（80×80。どの質問でも同じおだやかな顔）＋`bubble`（200×80 のふきだし。文字はアプリ側で入れる）。

## なでたときの反応（`svg/{light|dark}/pet/`、案内役と同じ 64×32）
`guide/guide_peek`（ふだん）→ `pet_squint`（目を細める）→ `pet_purr`（ごろごろ：ほおの横に小さな弧）。しっぽは `#tail` を回転させて動かす（1回、1.6秒以内）。音・振動の有無は、「演出を控えめにする」設定に従う。

## 絵の一覧と「何で変わるか」（ロシアンの事前確認 `docs/compliance/prereview_2026-11-23_experience_concepts.md` に合わせた対応表）

変えてよいきっかけは **日付・季節・時間帯・天気・ランダム・飼い主さんの操作（タップ・なでる）** だけ。**記録の中身や、記録の有無では絵を変えない。**

| 絵 | ファイル | 何で変わるか | 変えないもの・描かないもの |
|---|---|---|---|
| 窓の空・太陽・月 | `room/window_{morning,noon,evening,night}` | 端末の時刻（時間帯） | 記録の有無 |
| 窓の天気 | `room/weather_{cloudy,rain,snow}` | 季節に合わせたランダム（または飼い主さんが選ぶ）。端末の天気情報は使わない（位置情報・外部通信が必要になるため。ロシアン E-2） | 記録の中身 |
| 季節の小物 | `seasons/season_*` | 月（季節） | — |
| 家具（寝床・器・トイレ） | `room/bed`・`bowl_food`・`bowl_water`・`toilet_*` | 変わらない（いつも同じ） | 器の中身やトイレの様子を、記録で変えない（満杯のまま・汚れたまま、などは描かない） |
| 部屋の猫の場所・しぐさ | `room/cat_*`・`poses/pose_*` | 飼い主さんがタップした場所（その場所へ歩き、器のところでは器の後ろにすわる）・日付・ランダム | 記録の中身・有無（食べなかった日に寝ている、などの対応を作らない）。食べる・飲む姿は描かない |
| 毎日ちがう姿 | `poses/pose_*`（すわる・香箱・のびる・のぞく・窓の外） | 日付で順番に | 具合が悪そうな姿は入れない（うずくまる・ぐったり横たわる・目を細めて耐える・毛を逆立てる・吐く）。いまの5つはどれも、目を開けたおだやかな姿 |
| カード | `cards/card_*` | 問いの種類（ごはん・お水・トイレ・元気さ） | 答えによって絵を変えない |
| 絵日記の1コマ | 場面：`diary/diary_*`／隅のアイコン：`diary/item_*` | 場面は日付・ランダムで選ぶ（ロシアン E-1 の A 案）。隅のアイコンだけが、その日に記録した項目の種類を示す | 記録の中身（量・様子）で表情や場面を変えない。食べる・飲む動作は描かない。自動の文（「元気だったね」など）は付けない |
| 話しかける猫 | `guide/guide_peek`（推奨）／`talk/talk_face` | 質問の順番だけ | どの質問でも同じおだやかな顔。ロシアンの推奨に合わせ、話す猫は案内役（縁からのぞく猫）を使う。`talk_face` は予備 |
| なでたときの反応 | `pet/pet_squint`・`pet_purr`・`#tail` のゆれ | 飼い主さんがなでたとき | いつも同じ種類の穏やかな反応（目を細める・ごろごろ・しっぽを1回ゆらす）。そっぽを向く・逃げる・怒るは描かない |

- 動き：点滅や速い動きは使わない。「演出を控えめにする」（F-30）がオン、または OS の動きを減らす設定がオンなら、止まった絵1枚にする。
- 見送った猫は、毎日ちがう姿・なでる反応・部屋の演出の対象にしない。
- 「寝ている」場面は、横たわって目を閉じた姿にしない。寝床で丸まって、目を開けた姿にする（`cat_bed`・`diary_rest`）。
- 器のごはん（粒）は、いつも同じ量で描いている（記録とは関係しない飾り）。
