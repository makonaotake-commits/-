# 開発者アカウント登録の手順（Apple・Google）

作成：ボンベイ（2026-11-16）／ユーザー決定「今週中に登録を始める」（docs/kickoff_answers.md）を受けて作成。
費用・条件は変わることがあるため、**登録の直前に必ず公式ページで最新を確認する**。下の数字は 2026-11-16 時点の検索結果で、円の金額は未確認。

## まず決めること（確認シート：dev_account.html）
1. **名義：個人か法人か**
   - 個人：Apple は D-U-N-S 番号が不要。ストアの「販売元」には登録した個人名が表示される（公式で要確認）。
   - 法人：法人格が必要（屋号・任意の名称は不可）。D-U-N-S 番号が必要で、取得に最大5営業日程度（Apple 公式）。Google の法人アカウントはテスター条件の対象外とされる（二次情報。公式で要確認）。
2. **Google Play のテスター12人をどう集めるか**（個人名義の場合）
3. **登録に使う Apple ID / Google アカウント**（運営用に分けるか）

## Apple Developer Program
- 年会費：99 USD（地域ごとに現地通貨で表示。円の金額は登録画面で確認）
- 個人：D-U-N-S 不要／法人：D-U-N-S 必要（https://developer.apple.com/jp/support/D-U-N-S/）
- 手順：Apple ID の2ファクタ認証を有効化 → Apple Developer アプリまたは https://developer.apple.com/jp/programs/enroll/ から登録 → 本人確認 → 支払い
- 登録後にマンチカンが使うもの：TestFlight（iPhone でのテスト配信）、EAS ビルド

## Google Play Console
- 登録料：一度だけ 25 USD とされる（二次情報。公式の登録画面で確認）
- **2023年11月13日以降に作った個人アカウント**は、本番公開を申請する前に「**12人以上のテスターが14日間続けて参加するクローズドテスト**」が必要（https://support.google.com/googleplay/android-developer/answer/14151465）
  - 途中で途切れると14日を数え直しになるとの報告あり（二次情報）
  - → 12週の計画では、Android の本番公開の約3週前までにクローズドテストを始める必要がある（推測）
- 本人確認（身分証）・連絡先の確認がある

## 注意（ロシアン・マンチカンへ回すこと）
- 名義・販売元の表示は、監修者・運営者の開示文（未作成）と一致させる → ロシアン
- Bundle ID・アプリ名など登録時に決める値 → マンチカンが案を出す
- 公開前に、アプリ内の文言・ストア掲載文はロシアンのレビューを通す
