# ドキュメント索引

| フォルダ | 内容 | 担当エージェント |
|---|---|---|
| `requirements/` | 要件定義（概要・ペルソナ・ストーリー・機能/非機能・MVP） | requirements-analyst |
| `marketing/` | 市場分析・ポジショニング・チャネル・KPI・ローンチ計画 | marketing-strategist |
| `sns/trends/` | 週次トレンドレポート | sns-trend-researcher |
| `sns/instagram/` | プロフィール・投稿カレンダー・投稿案 | instagram-manager |
| `compliance/` | 医療・法令レビュー記録 | medical-compliance-reviewer |

## 使い方
- `/kickoff` … 初期ドキュメント一式を作成
- `/weekly-sns [本数]` … 週次の SNS 運用サイクル
- `/review <ファイル>` … コンプライアンスレビュー
- 個別に頼む場合：「requirements-analyst で食事記録機能のユーザーストーリーを書いて」など
