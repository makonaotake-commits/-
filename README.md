# じんケア — 慢性腎臓病（CKD）自己管理アプリ

CKD の患者さん本人が、検査値・食事・血圧などを記録して自己管理するための Web アプリ（PWA）です。
サーバー不要で、データはすべて端末のブラウザ内（localStorage）に保存されます。

> ⚠️ このアプリは記録と目安の確認のためのものです。診断や治療方針は必ず主治医の指示に従ってください。

## 機能

- **ホーム**: 最新の eGFR、CKD ステージ（G/A 区分）、重症度ヒートマップ、eGFR の年間変化量、今日の食事の達成状況、最新の血圧
- **検査値**: クレアチニン、シスタチンC、BUN、尿アルブミン/Cr比、尿蛋白/Cr比、K、P、Hb、尿酸、HbA1c の記録と推移グラフ
  - eGFR は日本人向け推算式で自動計算（eGFRcreat / eGFRcys）
- **食事**: 食塩・たんぱく質・エネルギー・カリウム・リン・水分の記録、1日合計と目標の比較、14日間の推移
  - 以前記録した料理名を選ぶと栄養量を自動入力
- **体調**: 血圧・脈拍・体重・尿量・服薬・むくみ・メモの記録、血圧/体重グラフ
- **設定**: プロフィール（生年月日・性別・身長）、食事目標の上書き、JSON 書き出し/読み込み、検査値の CSV 書き出し
- オフライン対応（Service Worker）、スマホのホーム画面に追加可能、ダークモード対応

## 計算の根拠

| 項目 | 内容 |
|---|---|
| eGFRcreat | 194 × Cr^-1.094 × 年齢^-0.287（女性 ×0.739） |
| eGFRcys | 男性 104 × Cys^-1.019 × 0.996^年齢 − 8、女性は ×0.929 してから − 8 |
| G 区分 | G1 ≥90 / G2 60–89 / G3a 45–59 / G3b 30–44 / G4 15–29 / G5 <15 |
| A 区分 | 尿アルブミン/Cr比 <30 / 30–299 / ≥300 mg/gCr（なければ尿蛋白/Cr比 <0.15 / 0.15–0.49 / ≥0.50 g/gCr） |
| 食事目標の目安 | 「慢性腎臓病に対する食事療法基準 2014年版」：食塩 3–6 g、たんぱく質 G3a 0.8–1.0 g/kg・G3b以降 0.6–0.8 g/kg（上限値を採用）、カリウム G3b ≤2000 mg・G4–5 ≤1500 mg、エネルギー 25–35 kcal/kg（標準体重 = 身長² × 22） |
| 降圧目標 | 蛋白尿あり 130/80 mmHg 未満、なし 140/90 mmHg 未満 |
| 急速な低下 | eGFR が年 −5 mL/分/1.73m² 以上低下 |

食事目標は設定画面で主治医・管理栄養士の指示値に上書きできます。

## 使い方

```bash
npm start      # http://localhost:8000 で起動（python3 が必要）
npm test       # 計算ロジックのテスト（Node.js 18 以上）
```

ビルド不要の静的ファイルなので、GitHub Pages などにそのまま置けば公開できます。

## 構成

```
index.html            画面の骨組み
styles.css            スタイル
js/app.js             画面描画・イベント処理
js/ckd.js             eGFR・ステージ・食事目標などの計算（純粋関数）
js/store.js           localStorage への保存
js/chart.js           SVG 折れ線グラフ
sw.js                 オフライン用 Service Worker
manifest.webmanifest  PWA 設定
tests/                ユニットテスト
```
