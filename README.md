# ねこ手帳 — 猫の慢性腎臓病(CKD)見守りアプリ(プロトタイプ)

腎臓病の猫と暮らす飼い主さんが、毎日の様子を10秒で記録し、受診のときに獣医師へ見せるためのWebアプリです。
データはすべてブラウザ内(localStorage / 写真・動画は IndexedDB)に保存され、サーバーは使いません。

> このアプリは診断や投薬の指示をしません。表示は受診の目安です。

## タブ

| タブ | 内容 |
|---|---|
| 今日 | 「いつも通り」ワンタップ記録、食欲・飲水・尿・体重・便・嘔吐・活動量・皮下輸液・メモ・写真/動画、投薬チェック、受診の目安アラート、体重の推移 |
| 治療 | 腎臓の状態(言われたステージ / Cre からの目安 / 記録からの「疑い」)、併発疾患、薬剤・サプリ、皮下輸液・食事・次回検査の計画 |
| 検査 | BUN・Cre・SDMA・P の記録、Cre からのステージ目安 |
| 病院用 | 直近14日の記録・検査値・メモを1枚にまとめて印刷/PDF |
| 情報 | ニュース・研究・セミナー(`news.json` を毎週日曜に定期タスクで更新) |
| 相談 | AI相談(準備中) |

## 情報タブの更新

`news.json` の `items` と `updated` を書き換えるだけで反映されます(読めない環境では `index.html` 内の既定値を表示)。

## 起動

```bash
npm start   # http://localhost:8000
```
