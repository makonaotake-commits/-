# CKD Care App（仮）

慢性腎臓病（CKD）患者向けアプリの企画・開発基盤。Claude Code のサブエージェントで要件定義、マーケティング、SNS 運用、医療コンプライアンスの各担当を分けている。

- 体制とルール → [`CLAUDE.md`](CLAUDE.md)
- エージェント定義 → [`.claude/agents/`](.claude/agents/)
- スラッシュコマンド → [`.claude/commands/`](.claude/commands/)
- 成果物 → [`docs/`](docs/README.md)

## はじめ方
```
claude
> /kickoff 対象は保存期CKD（G3〜G4）の患者と家族。まずは iOS/Android で MVP。
```
