# iPhone で試作を開く手順（Windows ＋ iPhone）

コードを読まなくても進められるように書いています。最初の1回は30分〜1時間くらいかかります。2回目からは「4. 毎回やること」だけです。

## しくみ（ひとことで）
Windows のパソコンで試作を「動かす係」を起動し、iPhone の **Expo Go**（無料アプリ）がそれを読み込んで表示します。パソコンと iPhone は **同じ Wi-Fi** につないでください。Apple の開発者アカウントは要りません。

---

## 1. iPhone の準備（1回だけ）
1. App Store で「**Expo Go**」を検索して入れます（提供元：650 Industries, Inc.）。
2. 開いてみて、ログインを求められたら、画面の案内に従って無料のアカウントを作るか、「あとで」を選びます（試作を見るだけならログインしなくても動きます）。

## 2. Windows の準備（1回だけ）
1. **Node.js** を入れます。ブラウザで `https://nodejs.org` を開き、「LTS（推奨版）」と書かれたほうをダウンロードして、案内どおり「次へ」で進めます。
2. **GitHub Desktop** を入れます。`https://desktop.github.com` からダウンロードして、案内どおりに進め、GitHub のアカウントでログインします。
3. GitHub Desktop で「File → Clone repository」を選び、このプロジェクトのリポジトリ（`makonaotake-commits/-`）を選んで「Clone」を押します。保存先は、例えば「ドキュメント\GitHub」のままで大丈夫です。
4. 画面上の「Current branch」を押して、`claude/keen-keller-zpcb0i` を選びます。

## 3. 試作を動かす準備（1回だけ）
1. GitHub Desktop の「Repository → Show in Explorer」で、プロジェクトのフォルダを開きます。
2. その中の **app** フォルダを開きます。
3. フォルダの上のアドレス欄（場所が書いてある欄）をクリックし、`powershell` と入力して Enter を押します。黒っぽい画面（PowerShell）が、app フォルダで開きます。
4. 次の1行を入力して Enter を押します。数分かかります。最後に何行か文字が出て、入力できる状態に戻れば完了です。
   ```
   npm install
   ```
   - 「スクリプトの実行が無効」という赤い文字が出た場合：PowerShell の代わりに、アドレス欄に `cmd` と入れて開く黒い画面（コマンドプロンプト）で同じことをしてください。

## 4. 毎回やること
1. 「3」の手順1〜3で、app フォルダの黒い画面を開きます。
2. 次の1行を入力して Enter を押します。
   ```
   npx expo start
   ```
3. しばらくすると、画面に **四角い QR コード** が出ます。
   - 「Windows セキュリティ」の画面で通信の許可を聞かれたら、「プライベート ネットワーク」に印を付けて「許可」を押してください。
4. iPhone の **カメラ** で QR コードを写し、出てきた「Expo Go で開く」を押します。
5. はじめは組み立てに1分ほどかかります。「ねこと、ゆっくり（試作）」の画面が出たら成功です。
6. 終わるときは、黒い画面で `Ctrl` キーを押しながら `C` を押します。

最新の試作にしたいときは、GitHub Desktop で「Fetch origin」→「Pull origin」を押してから、「4」をやり直してください。

## うまくいかないとき
| こんなとき | ためすこと |
|---|---|
| QR を写しても開かない／いつまでも読み込み中 | パソコンと iPhone が同じ Wi-Fi か確かめる。だめなら黒い画面で `Ctrl`＋`C` で止めて、`npx expo start --tunnel` で起動し直す（初回は追加の部品を入れてよいか聞かれるので `Y` を押して Enter） |
| 「Project is incompatible with this version of Expo Go」と出る | Expo Go のほうが新しくなっています。マンチカンに「Expo Go のバージョンに合わせて」と伝えてください（こちらで更新します） |
| 赤い画面にエラーが出る | 画面の写真（スクリーンショット）を撮って、マンチカンに送ってください |
| 会社や学校の Wi-Fi でつながらない | 自宅の Wi-Fi か、iPhone のテザリングにパソコンをつないで試す |

## Web 版とのちがい（今の試作）
- 記録は **その iPhone の Expo Go の中** に保存されます。ブラウザ版の記録とは別々です。
- フォントは、まだ iPhone 標準の文字です（Zen Maru Gothic・BIZ UDPGothic は次の段階で入れます）。
- 通知はまだ鳴りません（次の段階で、iPhone の中だけで出す通知として作ります）。
- 画面の言葉・値は、ブラウザ版と同じ仮のものです。

## わたし（マンチカン）が確かめたこと・確かめていないこと
- 確かめたこと：iPhone 向けの組み立て（書き出し）がエラーなく通ること。
- 確かめていないこと：実際の iPhone での表示と操作（この作業環境には iPhone がないため）。Windows での手順も、実機では試していません。つまずいたところを教えてもらえれば、この手順書を直します。
