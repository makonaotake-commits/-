# アカウントができたら：iPhone で「本番に近い試作」を動かす手順

Apple・Google・Expo のアカウントを作ったあとに、1回だけやる操作です。黒い画面（PowerShell）を使いますが、書いてあるとおりに打てば大丈夫です。わからないところで止まったら、画面の写真をマンチカンに送ってください。

> この手順は、Expo の公式の使い方をもとにした **下書き** です。作業環境から Expo の公式ページを開けなかったため、ボタンの名前などが少しちがうことがあります（未確認）。

## 0. 先にそろえるもの
| もの | どこで | メモ |
|---|---|---|
| 運営用の Apple ID | Apple | 新しく作ったもの |
| Apple Developer Program（個人） | developer.apple.com | 年会費がかかります。本人確認に数日かかることがあります。**ストアの「販売元」に、登録したお名前が出ます** |
| 運営用の Google アカウント | Google | 新しく作ったもの |
| Google Play Console（個人） | play.google.com/console | 登録料がかかります。公開の前に、テスター（12人を予定）によるテスト期間が必要です |
| Expo のアカウント | expo.dev | 無料。運営用のメールアドレスで作ります |
| アプリの名前など | 決定済み | アプリ名「ねこと、ゆっくり」、Bundle ID／パッケージ名 `jp.nekotoyukkuri.app`（あとから変えられません） |
| 配信地域・連絡先 | 決定済み | 第1弾の配信地域は **日本だけ**。ストアに出す連絡先は **運営用のメールアドレスだけ**（電話番号・住所は出さない） |

## 1. Expo にログインする（パソコン）
1. いつものように、`app` フォルダで黒い画面（PowerShell）を開きます（`EXPO_GO.md` の「3」と同じ）。
2. 次の1行を入力して Enter。メールアドレスとパスワードを聞かれたら、Expo のアカウントのものを入れます。
   ```
   npx eas-cli login
   ```
3. 次の1行で、このアプリを Expo のアカウントにつなぎます。質問には Enter（はい）で進めます。
   ```
   npx eas-cli init
   ```
4. GitHub Desktop を開くと、`app.json` が変わっています。左下の「Summary」に「Expo とつないだ」と書いて「Commit」→ 上の「Push origin」を押します（マンチカンが続きをできるようになります）。

## 2. iPhone を登録する（1回だけ）
1. 黒い画面で次の1行。質問には Enter で進みます。途中で Apple ID（運営用）のログインを聞かれます。
   ```
   npx eas-cli device:create
   ```
2. 画面に QR コード（またはリンク）が出ます。**iPhone のカメラ**で写して、Safari で開きます。
3. 「プロファイルをダウンロード」→ iPhone の **設定** を開くと上に「ダウンロード済みのプロファイル」が出るので、押して「インストール」。
4. iPhone の **設定 → プライバシーとセキュリティ → デベロッパモード** をオンにします（再起動を求められます）。

## 3. 開発用のアプリを作って入れる
1. 黒い画面で次の1行。Apple ID のログインと、「証明書を作りますか」などの質問が出たら、**Enter（おまかせ）** で進みます。
   ```
   npx eas-cli build --profile development --platform ios
   ```
2. Expo のサーバーでアプリが組み立てられます（15〜30分ほど。パソコンは閉じても大丈夫です）。
3. 終わると、QR コードとリンクが出ます（Expo のサイトの「Builds」にも出ます）。iPhone のカメラで写して、アプリを入れます。
4. ホーム画面に「ねこと、ゆっくり」が増えます。

## 4. 毎回の開き方（Expo Go の代わり）
1. パソコンの黒い画面で `npx expo start` を入力（`EXPO_GO.md` の「4」と同じ）。
2. iPhone では、**Expo Go ではなく**、さっき入れた「ねこと、ゆっくり」を開きます。パソコンが見つかれば、そのまま最新の試作が出ます。見つからないときは、パソコンの QR コードをカメラで写します。
3. 通知のボタン（飲めた・あとで・お知らせをお休みする）も、こちらで確かめられます。

## 5. あとで（公開の準備のとき）
- **TestFlight（iPhone の試用版）**：マンチカンが準備したあとに、次の2行を順に打ちます。
  ```
  npx eas-cli build --profile production --platform ios
  npx eas-cli submit --platform ios
  ```
  その前に、App Store Connect でアプリの登録（名前・Bundle ID の選択）が必要です。配信地域（「価格と配信状況」）は **日本だけ** を選びます。手順は、その時に1枚にまとめます。
- **Android**：`--platform android` で同じように作れます。テスター12人には、Google Play の「クローズドテスト」で配ります（その時に手順を作ります）。配信する国は **日本だけ** にします。

## 困ったとき
| こんなとき | ためすこと |
|---|---|
| `npx eas-cli` で「スクリプトの実行が無効」と出る | PowerShell の代わりに、アドレス欄に `cmd` と入れて開く黒い画面で同じことをする |
| Apple ID のログインで2ファクタ認証の番号を聞かれる | iPhone に出た6けたの番号を入れる |
| ビルドが「失敗」になる | Expo のサイトの「Builds」で失敗したビルドを開き、画面の写真をマンチカンに送る |
| アプリが開かない（「信頼されていない」など） | 「2」の4（デベロッパモード）がオンか確かめる |
